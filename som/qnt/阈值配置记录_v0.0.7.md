> 最后更新：2026-08-17 19:01 GMT+8
> 核心原则：**执行引擎阈值可调，风控阈值定死不变！**

---

## 一、参数总览表

### 执行引擎 spread_pct 阈值 > 0.05% (风控底线: > 0.22%) 价差灵敏度门槛，>0.05%就记录信号
### 执行引擎 net_profit_pct 阈值 > 0.01% (风控底线: > 0.1%) 净利灵敏度门槛，>0.01%就记录信号
### BI_SIDE_COST 0.12% 双边成本（手续费+滑点），交易所真实费率，不要改

| 模块 | 参数 | 当前值 | 说明 |
|------|------|--------|------|
| **执行引擎** | `spread_pct` | > 0.05% (风控底线: **> 0.22%**) | 价差灵敏度门槛，>0.05%就记录信号；实际交易必须>0.22%（=成本0.12% + 风控净利0.1%） |
| | `net_profit_pct` | > 0.01% (风控底线: **> 0.1%**) | 净利灵敏度门槛，>0.01%就记录信号；实际交易必须>0.1% |
| | `BI_SIDE_COST` | 0.12% | 双边成本（手续费+滑点），交易所真实费率，**不要改** |
| **风控层** | `MIN_NET_PROFIT_PCT` | > 0.1% ⚠️定死不变 | 最小净利要求，**实际交易门槛 = 0.12% + 0.1% = 价差必须 > 0.22%** |
| | `MAX_POSITION_PCT` | ≤ 20% | 单笔最大仓位 |
| | `MAX_STOP_LOSS_PCT` | ≤ 2% | 单笔止损 |
| | `MAX_CONSECUTIVE_LOSSES` | 5次暂停 | 连续亏损暂停 |
| | `MAX_DRAWDOWN_PCT` | 40%停止 | 最大回撤停止 |
| | `PROFIT_WITHDRAW_PCT` | 50%永不回流 | 盈利提取比例 |
| **模式发现** | `spread_threshold` | 0.08% | 模式识别灵敏度阈值（不影响实盘交易） |
| | `profitable_spread` | 0.10% | 可盈利模式判断阈值（不影响实盘交易） |

---

## 二、核心公式

```
实际交易门槛 = BI_SIDE_COST(0.12%) + MIN_NET_PROFIT_PCT(0.1%) = 价差 > 0.22%
```

---

## 三、联动关系

| 改哪个参数 | 影响 |
|-----------|------|
| `spread_pct` | 只变灵敏度，实际门槛不变 |
| `net_profit_pct` | 只变灵敏度，实际门槛不变 |
| `MIN_NET_PROFIT_PCT` | 实际门槛跟着变（0.12% + 新值） |
| `BI_SIDE_COST` | ❌ 不要改，这是交易所真实费率 |
