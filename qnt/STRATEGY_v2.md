## 一、核心概念澄清

### 1.1 什么是捡乌龙指（文章1009明确）

**正确定义：**
- 同一品种在**至少两个交易点**（不同交易所或同一所的不同厅）
- A厅价格异常偏离B厅（有参考系）
- 在A厅买入异常价格的同时，在B厅卖出正常价格
- 瞬间锁定利润，**不持仓等待价格恢复**

**关键区别：**
- ❌ 只在跌停板抄底 → 等待恢复 → 爆仓风险（文章999否定的）
- ✅ 有参考系同时对冲 → 瞬间锁定 → 零风险

### 1.2 什么是做市策略（文章4076）

- 双边挂单，赚取买卖价差
- 需要完整订单簿
- 有风险（可能成交后价格继续走）
- **这不是捡乌龙指**

## 二、当前系统问题诊断

### 2.1 之前的错误实现

| 问题 | 原因 | 影响 |
|------|------|------|
| 只扫单所现货vs永续 | 理解偏差 | 价差太小（0.024%），覆盖不了手续费 |
| 做市策略净利不足 | 主流币竞争激烈 | 净利0.0014%，低于0.1%阈值 |
| OKX深度bug | ccxt版本兼容 | 无法获取完整订单簿 |

### 2.2 正确的方向

**跨交易所捡乌龙指：**
- 同一币种在不同交易所的价格差异
- 小币种研究人少，价差更容易出现
- 必须同时买卖对冲，不等恢复

## 三、v2.0策略设计

### 3.1 核心逻辑

```python
# 捡乌龙指步骤：
1. 扫描多个交易所的同一币种价格
2. 找最低买价（ask最小）和最高卖价（bid最大）
3. 计算净利润 = 价差 - 双边手续费
4. 净利 > 阈值 → 立即执行对冲
5. 不等价格恢复，瞬间锁定
```

## 六、核心原则（背诵版）

1. **不等价格恢复** - 捡乌龙指必须瞬间对冲
2. **必须有参考系** - 只有一个交易点不是乌龙指
3. **提前锁定回收通道** - 废品回收站
4. **像机器一样执行** - 足够傻足够死板
5. **出来混，不要还** - 盈利取出不回流
6. **人少的地方才有钱** - 找冷门品种
7. **规则一旦建立，永远坚守** - 不离散化
