## SQL查询语句（常用）

```sql
-- 检查表行数
SELECT COUNT(*) FROM market_trades;
SELECT COUNT(*) FROM historical_trades;

-- 按平台统计价差
SELECT exchange, COUNT(*), AVG(spread_pct),
       COUNT(CASE WHEN spread_pct>=0.17 THEN 1 END)
FROM market_trades WHERE spread_pct IS NOT NULL
GROUP BY exchange;

-- 按币种统计价差
SELECT symbol, AVG(spread_pct), COUNT(CASE WHEN spread_pct>=0.15 THEN 1 END)
FROM market_trades WHERE spread_pct IS NOT NULL
GROUP BY symbol ORDER BY AVG(spread_pct) DESC;

-- 统计真实成交盈亏
SELECT symbol, COUNT(*), COALESCE(SUM(pnl),0)
FROM historical_trades WHERE pnl IS NOT NULL
GROUP BY symbol;
```
