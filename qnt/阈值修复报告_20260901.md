# QNT阈值修复报告（2026-09-01）

## 发现的问题

### 1. 阈值定义错误
- **位置**: `config.py`
- **问题**: `spread_pct=0.05`（应为0.17）
- **修复**: 改为0.17

### 2. 单位不一致导致误判
- **位置**: `risk_manager.py`
- **问题**: `MIN_NET_PROFIT_PCT=0.0001`（小数形式），但代码中乘以100变成0.01
- **修复**: 改为0.01（百分比形式），统一单位

### 3. 阈值检查逻辑错误
- **位置**: `execution_engine.py`
- **问题**: `if net_profit_pct < RiskManager.MIN_NET_PROFIT_PCT * 100:`
  - 0.0001 * 100 = 0.01，但注释写"要求净利>1%"，导致误判
- **修复**: 去掉`*100`，直接使用`MIN_NET_PROFIT_PCT=0.01`

### 4. PaperEngine缺少风控检查
- **位置**: `dual_engine.py`
- **问题**: PaperEngine没有检查`MIN_NET_PROFIT_PCT`
- **修复**: 添加`net_profit_pct < RiskManager.MIN_NET_PROFIT_PCT`检查

### 5. BacktestEngine缺少风控检查
- **位置**: `dual_engine.py`
- **问题**: BacktestEngine没有检查`MIN_NET_PROFIT_PCT`
- **修复**: 添加`net_profit_pct < RiskManager.MIN_NET_PROFIT_PCT`检查

### 6. 紧急平仓没有异常处理
- **位置**: `execution_engine.py`
- **问题**: 紧急平仓直接调用`create_order`，没有异常处理
- **修复**: 添加try-except，失败时记录日志

## 修复后的阈值体系
