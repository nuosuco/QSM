## 二、风控铁律

### 2.1 阈值配置（用户要求）
```python
# 成本线 = 0.16%（双边）
BI_SIDE_COST = 0.16

# 执行层阈值（可调灵敏度）
spread_pct = 0.17      # 价差门槛
net_profit_pct = 0.01  # 净利门槛

# 风控层阈值（定死不变）
MIN_NET_PROFIT_PCT = 0.0001  # 实际要求价差 > 0.17%
MAX_POSITION_PCT = 0.20      # 单笔仓位 ≤ 20%
MAX_CONSECUTIVE_LOSSES = 3   # 连续亏损3次暂停
MAX_DRAWDOWN_PCT = 0.30      # 最大回撤30%停止
```

### 2.2 风控检查链
```
价差检查(>0.17%) → 风控检查 → 最小金额检查 → 精度检查 → 成交概率 → 开仓
      ↓                ↓              ↓              ↓           ↓
   spread_pct     check_risk    position≥3U   amount≥1    random<0.6
```

### 2.3 实盘安全锁
```python
# 硬编码检查：config.live.enabled必须为True
if not self.config.live.enabled:
    logger.warning("⛔ 实盘交易未启用")
    return  # 跳过所有下单操作
```
