# QNT阈值配置记录 v0.0.5

## 一、核心概念：成本线

```
BI_SIDE_COST = 0.12% = 双边成本（手续费+滑点）

计算逻辑：
  净利 = 价差 - 0.12%
  
  价差 = 0.12% → 净利 = 0% → 不赚不亏（保本）
  价差 > 0.12% → 净利 > 0 → 开始盈利
  价差 < 0.12% → 净利 < 0 → 一定亏钱
```

## 三、人话解释：哪些能改、改了会怎样

### 1️⃣ 价差阈值 `spread_pct`
- **当前值**：0.03%
- **作用**：价差大于这个数才看
- **可改吗**：✅ 可以改
- **改了会怎样**：
  - 改成0.01% → 更敏感，更多机会（但可能亏钱）
  - 改成0.10% → 更保守，更少机会（但更稳）

**大白话**：这就像你买东西，价差太小你不感兴趣，价差大你才考虑。改成0.03%就是"稍微有点利差就看一眼"，改成0.10%就是"利差必须够大我才动"。

---

### 2️⃣ 净利阈值 `net_profit_pct`
- **当前值**：0（不亏就做）
- **作用**：净利大于这个数才交易
- **可改吗**：✅ 可以改
- **改了会怎样**：
  - 保持0 → 不亏钱就交易
  - 改成0.05% → 必须有利润才交易

**大白话**：这就像你做生意，0就是"不亏就行"，0.05%就是"至少赚点才行"。

---

### 3️⃣ 双边成本 `BI_SIDE_COST`
- **当前值**：0.12%
- **作用**：交易成本（手续费+滑点）
- **可改吗**：⚠️ 不建议改（这是交易所实际费率，改了会导致计算错误）

**大白话**：这是交易所收你的钱，你改不了。永续合约收0.04%，现货收0.02%，滑点再算0.02%，加起来单边0.06%，双边就是0.12%。这个是固定的，别改。

---

### 4️⃣ 最小净利 `MIN_NET_PROFIT_PCT`
- **当前值**：0.1%
- **作用**：风控级别的最小净利要求
- **可改吗**：✅ 可以改
- **改了会怎样**：
  - 改成0.05% → 更宽松
  - 改成0.2% → 更严格

**大白话**：这是风控层面的要求，比执行引擎的阈值更高。执行引擎说"0就交易"，风控说"不行，至少0.1%才允许"。

⚠️ **注意**：当前这个值只是打印在日志里，没有实际检查！需要修改代码才能生效。

---

### 5️⃣ 模式发现阈值 `spread_threshold` / `profitable_spread`
- **当前值**：0.08% / 0.10%
- **作用**：用于策略分析，不是直接控制交易
- **可改吗**：✅ 可以改，但不影响实盘交易

**大白话**：这两个参数是给"模式发现引擎"用的，用来分析历史数据找规律。不改它们，实盘交易照样跑。改了只是影响分析报告，不影响实际挂单。
