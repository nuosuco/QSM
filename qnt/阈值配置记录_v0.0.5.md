## 一、执行引擎阈值（核心）

**文件：** `/root/SOM/qnt/adaptive_system/execution_engine.py`

### 1.1 价差阈值
```python
# 第147-148行
if spread_pct < 0.05:
    continue
```
- **参数名：** `spread_pct`
- **当前值：** `0.05`（0.05%）
- **作用：** 价差必须大于0.05%才考虑交易
- **可修改：** ✅ 可以改
- **修改影响：**
  - 降低到0.03% → 更敏感，更多机会（但可能亏钱）
  - 提高到0.10% → 更保守，更少机会（但更稳）

### 1.2 净利阈值
```python
# 第152-153行
net_profit_pct = spread_pct - self.BI_SIDE_COST * 100
if net_profit_pct < 0.01:  # 至少要有0.01%净利才交易
    continue
```
- **参数名：** `net_profit_pct`
- **当前值：** `0.01`（0.01%）
- **作用：** 净利必须大于0.01%才交易
- **可修改：** ✅ 可以改
- **修改影响：**
  - 改成0 → 不亏钱就交易
  - 改成0.05% → 必须有利润才交易

### 1.3 双边成本（不建议修改）
```python
# 第26行
BI_SIDE_COST = TOTAL_COST * 2  # 双边成本 = 0.12%
```
- **参数名：** `BI_SIDE_COST`
- **当前值：** `0.12`（0.12%）
- **作用：** 交易成本（手续费+滑点）
- **可修改：** ⚠️ 不建议改
- **原因：** 这是交易所实际费率，改了会导致计算错误
- **构成：**
  - MAKER_FEE_RATE = 0.0004（0.04%）
  - SLIPPAGE_RATE = 0.0002（0.02%）
  - TOTAL_COST = 0.0006（0.06%）
  - BI_SIDE_COST = 0.0012（0.12%）
