# 捡乌龙指 v2.0 - Post-Only方案

## 核心问题

同时挂两个限价单，谁先成交无法控制：
- 现货卖单先成交 = 裸卖空 = 爆仓
- 永续买单先成交 = 裸多头 = 爆仓

## 解决方案：Post-Only订单

### 原理
Post-Only含义：只做Maker，不做Taker
- 如果订单会立即成交，自动取消
- 只作为挂单进入订单簿

### 操作步骤

1. 在永续挂限价买单，设置 post_only=true
   - 价格略低于当前bid（做Maker）
   - 如果永续有卖单 → 买单立即成交 → 自动取消 ❌
   - 如果永续没有卖单 → 买单挂单等待 → 成功 ✅

2. 在现货挂限价卖单，设置 post_only=true
   - 价格略高于当前ask（做Maker）
   - 如果现货有买家 → 卖单立即成交 → 自动取消 ❌
   - 如果现货没有买家 → 卖单挂单等待 → 成功 ✅

### 结果分析

情况A：两个订单都成交
- 我们同时持有永续多单和现货空单
- 完美对冲，无风险 ✅

情况B：只有一个成交
- 另一个订单自动取消
- 不会单边暴露 ✅

情况C：两个都取消
- 说明市场深度不足或价差太小
- 不操作，等待下次机会 ✅

## 代码实现

```python
import ccxt
import os

# 连接Bitget
bitget = ccxt.bitget({
    'apiKey': os.getenv('BITGET_API_KEY'),
    'secret': os.getenv('BITGET_API_SECRET'),
    'password': 'qntsomtop',
    'enableRateLimit': True
})

# Post-Only参数
params = {'postOnly': True}

# 获取当前价格
spot = bitget.fetch_ticker('RVN/USDT')
perp = bitget.fetch_ticker('RVN/USDT:USDT')

spot_ask = float(spot['ask'])
perp_bid = float(perp['bid'])

# 步骤1：挂永续买单（Post-Only）
perp_order = bitget.create_order(
    symbol='RVN/USDT:USDT',
    type='limit',
    side='buy',
    amount=10000,
    price=perp_bid - 0.00001,  # 略低于bid
    params=params
)

# 步骤2：挂现货卖单（Post-Only）
spot_order = bitget.create_order(
    symbol='RVN/USDT',
    type='limit',
    side='sell',
    amount=10000,
    price=spot_ask + 0.00001,  # 略高于ask
    params=params
)

# 检查结果
if perp_order and spot_order:
    print(f"✅ 成功！两个订单都已挂出")
elif perp_order and not spot_order:
    print(f"⚠️ 永续买单成功，现货卖单取消（市场深度不足）")
elif not perp_order and spot_order:
    print(f"⚠️ 现货卖单成功，永续买单取消（市场深度不足）")
else:
    print(f"❌ 两个订单都取消，等待下次机会")
```

## 风险对比

| 方案 | 爆仓风险 | 操作复杂度 |
|------|---------|-----------|
| 同时挂两个限价单 | ❌ 高 | 低 |
| Post-Only订单 | ✅ 零 | 中 |
| 时间差策略 | ✅ 低 | 高 |

## 结论

使用Post-Only订单可以同时挂单且不会爆仓！
