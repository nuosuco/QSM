# 捡乌龙指正确方法（根据碧树西风文章）

## 核心定义（文章1009）

**什么是乌龙指？**
- 同一品种，在至少两个交易点（现货厅、永续厅）
- A厅有人敲错价格（如10000卖成1000）
- B厅价格正常不动（参考系）
- 这就是乌龙指

**判断标准：**
- 有参考系 = 是乌龙指
- 只有一个交易点 = 只是价格波动，不是

## 正确的操作方法（文章704）

### 场景举例
一个品种，有现货厅、永续厅两个窗口：
- 永续厅：有人敲错价，价格打到9折
- 现货厅：价格正常（参考系）

### 操作步骤
1. **永续厅开多**：200倍杠杆，挂9折买入
2. **现货厅开空**：同时挂原价卖出
3. **成交瞬间锁利**：永续买成了，现货卖也成交了
4. **两边平仓**：永约有赚，现货有亏，互相抵消
5. **落袋为安**：利润 = 价差 - 手续费

### 为什么不会爆仓？
```
永续多单 + 现货空单 = 天然对冲
价格涨：永续赚，现货亏 → 抵消
价格跌：永续亏，现货赚 → 抵消
→ 净值不变，不会爆仓
```

### 为什么用高杠杆？
```
本金$1，200倍杠杆 → 持仓$200
价差3%，利润$6
不加杠杆：利润$0.03
加200倍：利润$6（200倍放大）
```

### 利息问题
- 不成交 = 不支付利息
- 成交后 = 瞬间平仓 = 不持仓 = 不支付利息
- 对比房贷：有利息，还有持仓风险

## 风险控制（文章527）

### 核心风险：执行风险
- 永续成交了，现货没成交 → 裸多头
- 现货成交了，永续没成交 → 裸空头
- **解决方案：必须同时成交，否则放弃**

### 为什么不用押涨跌？
```
押涨跌：
- 需要持仓时间
- 有持仓风险
- 利润不确定

捡乌龙指：
- 零持仓时间
- 无持仓风险
- 利润确定（锁定价差）
```
