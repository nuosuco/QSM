```

  → 立即平仓，锁死利润

  → 立即市价卖出RVN（现货）

  → 立即市价买入RVN（永续）
  → 完成对冲

  → 取消订单，等待下次机会
```

## 步骤7：盈利提取

```

```

---

## 关键原则

1. **同平台**：必须在同一交易所操作
2. **同时挂单**：永续买单和现货卖单必须同时挂出
3. **不等恢复**：不等价格回归，瞬间锁利
4. **不持仓**：成交后立即平仓，不留过夜
5. **盈利提取**：每次盈利取50%永不回流
