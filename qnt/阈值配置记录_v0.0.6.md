# QNT阈值配置记录 v0.0.6

## 📋 快速参考表

| 模块 | 参数 | 当前值 | 说明 |
|------|------|--------|------|
| 执行引擎 | spread_pct 阈值 | > 0.05% | 价差必须大于0.05%才考虑 |
| | net_profit_pct 阈值 | > 0.01% | 净利必须大于0.01%才交易 |
| | BI_SIDE_COST | 0.12% | 双边成本（手续费+滑点） |
| **风控层** | **MIN_NET_PROFIT_PCT** | **> 0.1%** ⚠️ | **最小净利要求（定死不变）** |
| 模式发现 | spread_threshold | 0.08% | 模式识别阈值 |
| | profitable_spread | 0.10% | 可盈利阈值 |

---

## 🔢 联动公式

```
实际交易门槛 = 最低成本0.12% + 最低净利0.1% = >0.22%
              ↑                    ↑
          交易所手续费           风控要求利润
```

- ✅ 改 `spread_pct` / `net_profit_pct` → 只改变灵敏度，**不影响实际门槛**
- ⚠️ 改 `MIN_NET_PROFIT_PCT` → 实际门槛跟着变（比如改0.05% → 门槛变0.17%）
- ❌ 改 `BI_SIDE_COST` → 不要改！这是交易所真实费率
