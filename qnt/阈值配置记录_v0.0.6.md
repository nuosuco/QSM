## 一、参数总览表

### 1.1 执行引擎层（灵敏度门槛，可调）

| 参数 | 当前值 | 说明 | 风控底线 |

| 参数名 | 当前值 | 单位 | 说明 | 风控底线 |
|--------|--------|------|------|----------|
| `spread_pct` | **0.05%** | 价差 | 价差必须大于此值才触发信号记录 | > 0.22%（否则亏钱） |
| `net_profit_pct` | **0.01%** | 净利 | 净利必须大于此值才标记为可交易机会 | > 0.10%（否则亏损） |
| `BI_SIDE_COST` | **0.12%** | 双边成本 | 手续费+滑点，交易所真实费率（永续0.06% Maker + 现货0.06% Maker） | ❌ **不要改** |

### 1.2 风控层（定死规则，不可改）

| 参数名 | 当前值 | 单位 | 说明 |
|--------|--------|------|------|
| `MIN_NET_PROFIT_PCT` | **0.1%** | 最小净利 | ⚠️ 定死不变！决定实际交易门槛。价差必须 > 成本线+0.1% 才能交易 |
| `MAX_POSITION_PCT` | **20%** | 最大仓位 | 单笔仓位 ≤ 总资金20% |
| `MAX_STOP_LOSS_PCT` | **2%** | 止损 | 单笔止损 ≤ 总资金2% |
| `MAX_CONSECUTIVE_LOSSES` | **5次** | 连续亏损 | 连续亏损5次暂停交易 |
| `MAX_DRAWDOWN_PCT` | **40%** | 最大回撤 | 最大回撤40%停止交易 |
| `PROFIT_WITHDRAW_PCT` | **50%** | 盈利提取 | 盈利取出50%永不回流 |

### 1.3 模式发现层（观察用，不影响实盘）

| 参数名 | 当前值 | 单位 | 说明 |
|--------|--------|------|------|
| `spread_threshold` | **0.08%** | 模式识别 | 模式识别灵敏度阈值 |
| `profitable_spread` | **0.10%** | 可盈利判断 | 判断是否为可盈利模式 |

## 二、核心联动公式

```
成本线 = BI_SIDE_COST = 0.12%（永续Maker 0.06% + 现货Maker 0.06%）

实际交易门槛 = 成本线(0.12%) + 最低净利要求(0.10%) = >0.22%

净利 = 价差 - 0.12%
  • 价差 = 0.12% → 保本
  • 价差 > 0.12% → 盈利
  • 价差 < 0.12% → 亏钱
```

## 三、可改什么 vs 不可改什么

| 改动类型 | 参数 | 效果 | 风险 |
|----------|------|------|------|
| ✅ 可改 | `spread_pct` / `net_profit_pct` | 只变灵敏度，不影响实际交易门槛 | 无 |
| ⚠️ 谨慎 | `MIN_NET_PROFIT_PCT` | 实际门槛跟着变（0.1%→改后的值） | 有 |
| ❌ 禁止 | `BI_SIDE_COST` | 交易所真实费率，改了会算错盈亏 | 致命 |
| ❌ 禁止 | 风控层任何参数 | 碧树西风16年验证的铁律 | 致命 |
