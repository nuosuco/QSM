# QNT阈值配置记录 v1.0
**更新日期**: 2026-09-01
**版本**: 三引擎系统v1.0

## 核心阈值（定死不变）

| 参数 | 值 | 说明 |
|------|-----|------|
| MIN_NET_PROFIT_PCT | 0.0001 (0.01%) | 净利必须 > 0.01%，定死不变 |
| MAX_POSITION_PCT | 0.20 (20%) | 单笔仓位 ≤ 20% |
| MAX_STOP_LOSS_PCT | 0.02 (2%) | 止损 ≤ 2% |
| MAX_CONSECUTIVE_LOSSES | 5 | 连续亏损5次暂停 |
| MAX_DRAWDOWN_PCT | 0.40 (40%) | 最大回撤40%停止 |
| PROFIT_WITHDRAW_PCT | 0.50 (50%) | 盈利50%提取永不回流 |

## 执行层阈值（可调灵敏度）

| 参数 | 值 | 说明 |
|------|-----|------|
| spread_pct | 0.17 | 价差阈值 > 0.17% |
| net_profit_pct | 0.01 | 净利阈值 > 0.01% |
| BI_SIDE_COST | 0.16% | 双边成本（不改） |

## 实际交易门槛

```
成本线 = 0.16%
净利要求 = 0.01%
实际门槛 = 价差 > 0.17%
```

## 风控检查顺序

1. 价差检查：spread >= 0.17%
2. 风控检查：check_risk()
3. 最小金额检查
4. 精度检查
5. 成交概率检查（60%）
6. 持仓检查

## 交易所限制

| 交易所 | 最小金额 | 最小精度 | 状态 |
|--------|----------|----------|------|
| Gate | 3U | 1币 | ✅ 可用 |
| Bitget | 5U | 按币种 | ✅ 可用 |
| HTX | **禁用** | - | ❌ 已禁用 |

## 关键教训

- HTX亏损根因：旧代码 config.live.enabled 默认为 True
- 修复：默认改为 False + 硬编码安全检查
- HTX API密钥已清空，永久禁用
