## 一、核心概念（必须背诵）

### 1.1 什么是捡乌龙指

**正确定义：**
- 同一币种在**同一平台**的两个"厅"
- 永续厅价格异常偏离（有人敲错价）
- 现货厅价格正常（参考系）
- 永续开多 + 现货卖单 → 瞬间锁利

**关键原则：**
1. 必须在同平台操作（不能跨平台）
2. 不能持仓过夜（持仓就爆仓）
3. 不等价格恢复（瞬间对冲）
4. 必须有参考系（至少两个交易点）

### 1.2 为什么不会爆仓

```
永续多单 + 现货卖单 = 天然对冲
→ 成交瞬间锁死利润
→ 没有持仓 → 没有爆仓风险
```

### 1.3 为什么用高杠杆

```
本金$1，200倍杠杆 → 持仓$200
价差3% → 利润$6
不加杠杆：利润$0.03
加200倍：利润$6（放大200倍）
```

### 1.4 利息问题

- 不成交 = 不支付利息
- 成交后瞬间平仓 = 不持仓 = 不支付利息

## 二、正确操作流程

```
1. 扫描所有币种
   └─ 检查永续ask vs 现货bid
   
2. 发现异常价差（>2%）
   └─ 确认现货有足够深度
   
3. 同时下单
   └─ 永续开多（挂单等成交）
   └─ 现货卖单（挂单等成交）
   
4. 两边成交
   └─ 立即平仓，不留持仓
```

---

## 三、风险管理

```
单笔止损 ≤ 总资金 2%
单品种仓位 ≤ 总资金 20%
连续亏损 5 次暂停交易
盈利取出 50% 永不回流
最大回撤控制 < 40%
```

---

## 四、执行要求

1. **速度**：发现机会后3秒内完成下单
2. **深度**：确保两边都有足够流动性
3. **同时**：永续买单和现货卖单必须同时挂出
4. **平仓**：两边都成交后立即平仓
