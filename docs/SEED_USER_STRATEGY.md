# SOM 松麦 · 种子用户获取策略

> 冷启动阶段 · 精准获客 · 信任前置  
> 更新日期：2026-07-28

## 核心原则

**中医养生是高度垂直的圈子，别想着大众投放，走精准口子。**

- 先让用户觉得"这儿辨证准"，再谈买东西
- 登录时机往后推：先玩起来 → 做完体质测评 → 最想保存结果时 → 弹"登录后永久保存+多端同步"
- 内容种草 > 硬广投放

## 渠道一：内容种草（公众号/小红书）

### 选题方向

| 类型 | 示例标题 | 引流钩子 |
|------|---------|---------|
| 体质自测 | "九种体质自测表，你是哪种？" | 文末二维码→完整测评 |
| 节气食疗 | "大暑养生：这4种食材别错过" | 文中嵌入节气模块链接 |
| 症状解读 | "失眠多梦？中医教你辨证分型" | 引导体验小麦SOM对话 |
| 药食同源 | "黄芪泡水喝对吗？看体质！" | 知识库查询入口 |
| 误区纠正 | "湿气重就喝薏米水？错！" | 辨证引擎体验 |

### 发布节奏

- 公众号：每周 2-3 篇（周二/四/六晚 8 点）
- 小红书：每天 1 条图文笔记（早 7 点或晚 9 点）
- 内容复用：一篇长文拆成 3-5 条短笔记

### 关键指标

- 单篇阅读 → 测评转化率 > 5%
- 测评完成 → 注册转化率 > 30%

## 渠道二：社群渗透

### 目标群类型

1. **中医养生群** — 最直接，用户对辨证有认知基础
2. **宝妈群** — 关注孩子积食、脾胃调理，付费意愿强
3. **亚健康白领群** — 失眠、疲劳、颈椎问题，需要轻量方案
4. **中老年养生群** — 慢病管理需求，粘性高但转化慢

### 渗透策略

- **不硬广**：先以"养生知识分享者"身份入群，日常解答问题
- **体质测评是天然钩子**："群里福利，免费体质测评，扫码即可"
- **节气节点推送**：每个节气前一天发"明日XX节气，养生要点+食疗方"
- **案例分享**：征得同意后分享"用户通过辨证调整饮食后改善"的故事

### 执行要点

- 每个群安排 1 个"养生顾问"人设（可以是小麦SOM的拟人化）
- 每周至少 3 次有价值的分享（不是广告）
- 每月 1 次群内"体质答疑"活动

## 渠道三：测评裂变

### 机制设计

```
用户完成体质测评
    ↓
生成专属结果卡片（含体质名称+特征+调养建议）
    ↓
卡片底部带小程序码/网页链接
    ↓
分享到朋友圈/微信群 → 好友扫码测自己的
    ↓
新用户完成测评 → 双方各得积分奖励
```

### 卡片设计要素

- 视觉：中国风配色（墨绿+米白），体质名称用书法字体
- 内容：体质名 + 3 个典型特征 + 1 句调养口诀
- 钩子："你的体质是 XX，全国仅 X% 的人是这种体质"（制造稀缺感）
- 行动点："测测你的体质 →" 按钮/二维码

### 激励设计

- 邀请 1 人完成测评：+10 积分
- 邀请 3 人：解锁"高级食疗方案库"
- 邀请 10 人：获得"养生达人"徽章 + 商品优惠券

## 渠道四：信任前置

### 用户旅程优化

```
首次访问（无需登录）
    ↓
体验小麦SOM对话（免费辨证）
    ↓
查看养生谷（节气/护眼/知识库）
    ↓
完成体质测评（核心转化点）
    ↓
弹出："登录后永久保存体质档案 + 多端同步 + 积分奖励"
    ↓
注册/登录（转化率最高时机）
    ↓
个性化推荐（基于体质推荐商品/食疗）
```

### 关键设计

- **前 3 次对话不要求登录**：让用户先感受到价值
- **体质结果本地缓存**：即使不登录也能看到结果，但提示"登录后可永久保存"
- **商品推荐后置**：辨证结果出来后再推商品，不要一上来就卖货
- **免责声明**：所有辨证结果标注"养生建议仅供参考，不构成医疗诊断"

## 风险与应对

| 风险 | 应对 |
|------|------|
| 内容同质化严重 | 突出"辨证个性化"差异点，不做泛养生科普 |
| 用户测完就走 | 节气推送 + 每日签到 + 体质跟踪形成回访闭环 |
| 社群被踢 | 先提供价值再引流，遵守群规，不刷屏 |
| 转化率低 | A/B 测试登录弹窗时机，优化卡片文案 |
| 合规风险 | 严格区分"养生建议"与"医疗诊断"，加免责声明 |
