## 一、量子电路编译器架构

```
┌─────────────────────────────────────────────────────────────┐
│                    QASM量子电路                              │
│  qreg q[2]                                                  │
│  h q[0]                                                     │
│  cx q[0], q[1]                                              │
│  var m0 = measure q[0]                                      │
└────────────────────┬────────────────────────────────────────┘
                     │ QCL编译器
                     ▼
┌─────────────────────────────────────────────────────────────┐
│                    QBC字节码                                 │
│  PUSH_INT 2          ← qreg大小                              │
│  BUILTIN qreg_create   ← 创建量子寄存器                      │
│  LOAD_VAR g          ← 获取寄存器ID                          │
│  PUSH_INT 0          ← qubit索引                             │
│  BUILTIN apply_h     ← 哈达玛门                              │
│  ...                                                     │
│  BUILTIN measure     ← 测量                                  │
└────────────────────┬────────────────────────────────────────┘
                     │ QVM虚拟机
                     ▼
┌─────────────────────────────────────────────────────────────┐
│                    C种子量子门                               │
│  qreg_create(n)    → 创建n量子位寄存器，返回id               │
│  apply_h(id, q)    → 哈达玛门                                │
│  apply_t(id, q)    → T门                                    │
│  apply_cx(id, c, t) → CNOT门                                 │
│  measure(id, q)    → 测量并坍缩                              │
└─────────────────────────────────────────────────────────────┘
```

## 四、量子门实现细节

### 1. qreg_create(n)
```c
// 创建n量子位寄存器
// 返回: 寄存器ID (0-15)
// 失败: -1
```

### 2. apply_h(id, q)
```c
// 哈达玛门作用于第q个量子位
// H|0> = (|0> + |1>)/√2
// H|1> = (|0> - |1>)/√2
```

### 3. apply_cx(id, c, t)
```c
// CNOT门：控制位c，目标位t
// |00> → |00>, |01> → |01>
// |10> → |11>, |11> → |10>
```

### 4. measure(id, q)
```c
// 测量第q个量子位
// 返回: 0或1
// 坍缩: 测量后量子态坍缩到对应基态
```
