### QSCL 不同起点叠加态并行 · 多模态统一识别/推理/生成（核心洞察：生成=识别对称反向，共用 W、共用 4 态）

```
              ┌─────────────────────┐
  像素 ────→ │  W[k] × 像素        │ → 类序号 k          [识别 = 内积 + argmax]
              │  (32 态 = 8 批×4 叠加态 加权)             │
  类 k ────→ │  W[k]               │ → 64 像素原型        [生成 = 直接读出]
              │                                        │
  类 k ────→ │  W[k] + 4 态投票坍缩   │ → 8×8 字形         [推理/生成]
              └─────────────────────┘
       识别 = 生成的对称反向，共用同一份 W、共用同一组 4 态
```

- 识别走 argmax：把 64 像素对 32 个 s-权重（`qscl_unified_b{0..7}_s{0..3}.w`，每文件 515 类×64 像素，8 批×515=4120 字）做内积，全局 argmax 得类 k。
- 生成=直接读 W[k]：取该批 4 态逐像素投票（≥3 态置 1）坍缩成 8×8 字形。
- 推理=生成加扰动坍缩。三者**共用同一 W、同一 4 态**，识别与生成互为对称反向，无翻译层。
(生成→编译→验证→快照→永续,容错回退)。

## 二、核心理论（中华定调）

**生成 = 识别的对称反向，共用 W 矩阵。**
- 识别：像素 → argmax(W[k]·像素) → 类序号 k
- 生成：类 k → W[k] 行向量(原型像素) → 直接读出
- 推理/生成：W[k]+噪声 → 4态并行取行 → 投票坍缩 → 阈值化 → 8×8 二值图 → 光栅化彝文
- W[k] 既是识别模板也是生成原型，识别与生成数学上互为逆运算。看/想/写不分类，输入输出同构都是像素。

**4态真叠加态并行**（三要素：同时运行 / 不同随机起点 / 最后汇聚投票）
- 4120字 → 8批（每批515字）→ 每批4态不同seed → 32份独立权重
- 合成1个=单模型=错；4态并行提速约25×（0.2s/查询）

**文字=图片=视频=像素序列**，一套整数点积搞定，无需三套编码器。

## 训练方法铁律

1. 输入是像素不是码点（码点=人给的编号，不是字符的样子）。
2. 对比式感知机（W[正确类]+=input 且 W[错分预测类]-=input），非Hebbian单增强（后者60%天花板不收敛）。
3. 自指准确率不可信，真泛化用未训练像素验证。
4. 32份权重MD5必须全不同=真独立学习。
5. 合并用4态投票非均值。
6. 8×8像素有物理天花板≈99.4%（像素完全相同的字形无法区分）。
