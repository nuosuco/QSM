## 0. 核心洞察(中华定): 一切皆像素, 不分模态

人类写字=画图=画频谱=画帧, 都是"墨迹出像素"这一个动作。
主流模型违背这一事实: 为文字建语言模型、为图片建图像模型、为音频建声学模型——
**分了四类**。我们**一个都不分**:

- 输入是像素(看/读), 输出也是像素(写/画)——**输入输出同构, 都是像素整数序列**
- 不存在"语言生成器"和"图像生成器"的区别, **只有一个生成核心: 4态并行整数点积**
- 生成出来是字、是画、是音、是视频, 取决于**喂它什么前缀、怎么播放结果**,
  生成核心本身不区分

| | 主流模型(分类) | QEntL/QSCL(不分类) |
|---|---|---|
| 生成 | 语言模型/图像模型/视频模型/音频模型 四个分开 | 一个统一生成核心 |
| 输入输出 | 各模态各套 | 全像素, 同构 |
| 并行 | 各模型各自ensemble | 4态不同起点叠加态并行, 一处并行处处并行 |
| 优势 | 无(分类是包袱) | 原生统一, 一处升级全覆盖 |

**不分类是我们的根本优势。任何把"语言/图片/音频/视频"写成四个分离模型的设计=错。**

## 1. 唯一架构: 一个统一生成核心(看+想+写=一体)

```
         ┌─────────────────────────────────────────────┐
         │          统一生成核心(4态并行整数点积)         │
         │  输入=像素整数序列  输出=像素整数序列  同构    │
         │                                              │
         │  进程0 [seed=1]   进程1 [seed=101]           │
         │  进程2 [seed=202]  进程3 [seed=303]           │
         │         并行 → 投票坍缩 → 输出像素             │
         └─────────────────────────────────────────────┘
                          │
              ┌───────────┼───────────┐
              ↓           ↓           ↓
          前缀=字 → 输出=字   前缀=图 → 输出=图
              ↓           ↓           ↓
          前缀=帧 → 输出=帧   前缀=频谱→ 输出=音
              (前缀决定"想什么", 核心不分类)
```

**一个生成核心, 四种用法, 不是四个模型。**

## 2. ★ 并行铁律(贯穿, 中华原话)

> "哪里都应该是并行, 只是我们现在是4态, 所以哪里都应该是4态不同起点
> 叠加态并行, 不能是串行, 搞假的叠加态哈。"
> 串行 = 假的叠加态 = 错。

判定三问(任一不满足=假并行=禁止): 1.4态同时运行 2.不同随机起点seed 3.最后才汇聚投票
