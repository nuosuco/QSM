## 0. 核心洞察(中华定): 文字就是图片

人类写字就是画图——笔画出墨迹像素 = 画图出墨迹像素, 同一动作。
所以**不需要**文字编码器/图片编码器/视频编码器三套 —— 像素就是像素, 不管代表字还是画。
这决定了整个架构天生统一: 一套整数点积 + 4态并行, 全覆盖。

| | 主流模型 | QEntL/QSCL |
|---|---|---|
| 看字 | 图片→编码器→向量→对齐文字(间接) | 像素整数→点积→标签(原生) |
| 看/读/文字/图/音/视频 | 三套编码器(text+image+frame) | 一套整数点积 + 4态并行 |
| 并行方式 | ensemble(起点相同=假并行) | 4态独立起点(真叠加态并行) |

## 1. 统一生成架构(看/读/想/写/画 + 多模态)

### 四个基本算子(全是整数运算, QEntL全栈)

| 算子 | 方向 | 功能 | 模态覆盖 |
|---|---|---|---|
| 算子1 QSCL识别器(看/读) | 像素 → 标签 | 认字/读图/认帧 | 输入端 |
| 算子2 QSCL-LM语言模型(想) | 序列 → 下一字 | 造词造句写文章 | 文字生成 |
| 算子3 反向QSCL(写/画) | 标签 → 像素 | 写字/画图/画频谱/画帧 | 文字·图片·音频·视频 输出 |

**"统一输出"的技术含义**: 文字/图片/音频/视频共用算子3(反向QSCL)这一个"画像素"核心——
- 文字输出 = 算子2想(逐字)+算子3画每字
- 图片输出 = 算子3直接画整幅像素
- 音频输出 = 算子3画频谱像素 → 播放成声波
- 视频输出 = 算子3逐帧画像素 → 时序播放

**四条路径都共用算子3, 所以不需要为每种模态各写一套生成器。**

## 2. ★ 并行铁律(贯穿每一层, 中华原话)

> "哪里都应该是并行, 只是我们现在是4态, 所以哪里都应该是4态不同起点叠加态并行,
>  不能是串行, 搞假的叠加态哈。"

**判定(三问, 任一不满足=假并行=禁止):**
1. 4态是否**同时**运行?(同时=真并行)
2. 4态是否从**不同随机起点(seed)**开始?(不同起点=真叠加)
3. 是否**最后才汇聚投票**?(先各自算完再坍缩=真叠加态)

**真并行(✅):** 4个独立QVM进程 `&` + `wait`, 各起各算, 最后投票
**假并行(❌禁止):** `for s in 0 1 2 3` 写在一起但一个接一个串行

详细架构与升级案例: `docs/PARALLEL_ARCH_MANIFESTO.md`

## 5. 阶段C: 语言生成模型 QSCL-LM(★ 待建, 必须4态并行)

**目的**: 给前缀输出下一字 —— 让模型会"想", 是造词造句写文章的核心。

**架构(QEntL全栈, 4态叠加态并行):**
- 输入: 前缀2字 联合索引(one-hot 6561维)
- 输出: 81类(argmax=下一字索引)
- 训练: 感知机对比式(已验证可收敛98%): argmax≠目标 → W[目标]+=数据, W[预测]-=数据
- **4态: seed 1/101/202/303, 各自独立QVM进程并行训练 → 生成时4态并行投票选下一字**
- 权重: `qscl_lm_s{0-3}.w` 4份(不同起点=真叠加态)

**构建步骤:**
1. 初始化4份权重, 不同随机种子(4态并行初始化)
2. 读 qscl_lm_pairs.txt, 4态各自并行前向+感知机更新
3. 循环多轮直到 argmax 正确率>95%
4. 4态独立存盘 → 生成时4态并行 + 真多数投票选下一字

**阶段C完成条件:** [SOS] → 4态并行自回归生成完整SOV句, 4态投票, 否定/过去/将来正确, vocab_map合法。

**当前状态:** 训练器脚本 `build/train_qscl_lm_v2.qentl` 已建(纯QEntL), 待4态并行训练。

## 6. 阶段D: 反向QSCL(画像素, ★ 待建, 4态并行) + 统一输出

**目的**: 标签 → 像素, 让模型能"写"和"画"。这是文字/图片/音频/视频统一输出的关键算子。

**架构(4态并行):**
- 反向权重: `qscl_rev_b{0-7}_s{0-3}.w` (32份, 与识别器对称)
- 训练: 识别器反向 —— 给标签, 画像素, 与真实像素对比更新(感知机)
- **4态并行画像素 → 投票坍缩成最终像素**

**统一输出流水线(核心!):**
- **文字**: 算子2(想逐字) + 算子3(画每字像素) = 写字
- **图片**: 算子3直接画整幅像素 = 画图
- **音频**: 算子3画频谱像素 → 播放成声波 = 发语音
- **视频**: 算子3逐帧画像素 → 时序播放 = 放视频

四条路径共用算子3这一个并行画像素核心 —— 这就是"统一输出", 不需要分模态写。
