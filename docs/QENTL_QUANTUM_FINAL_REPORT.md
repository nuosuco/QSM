## 四、关键技术决策

### 1. 量子门实现位置
- **决策**: 在C种子实现，不在QVM实现
- **原因**: QVM值模型不支持浮点数（.字符非法），量子态向量需要复数运算
- **结果**: 量子门在C中高效实现，QCL直接emit BUILTIN调用

### 2. QASM语法设计
- **决策**: 采用语句形式而非函数调用
- **形式**: `h q[0]` 而非 `h(q[0])`
- **原因**: 更符合量子电路描述习惯，与QASM标准兼容

### 3. 纠缠验证方法
- **决策**: 使用Bell态（H+CNOT）验证纠缠
- **理论**: Bell态 |Φ+> = (|00> + |11>)/√2
- **验证**: 测量结果应该完全相关（100%纠缠率）

## 五、量子门数学实现

### 哈达玛门 H
```
H|0> = (|0> + |1>)/√2
H|1> = (|0> - |1>)/√2

矩阵形式:
H = 1/√2 * [[1, 1],
            [1, -1]]
```

### T门
```
T|0> = |0>
T|1> = e^(iπ/4)|1>

矩阵形式:
T = [[1, 0],
     [0, e^(iπ/4)]]
```

### CNOT门
```
CNOT|00> = |00>
CNOT|01> = |01>
CNOT|10> = |11>
CNOT|11> = |10>
```

### 测量
```
测量量子态 |ψ> = α|0> + β|1>
结果: 0 (概率|α|²) 或 1 (概率|β|²)
坍缩: 测量后态变为对应本征态
```
