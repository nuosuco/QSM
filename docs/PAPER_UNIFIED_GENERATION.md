## 摘要

主流多模态模型为文字/图片/音频/视频各配独立编码器, 在向量空间"对齐"——
这是一条间接的翻译路径。本文提出根本不同的架构: **文字=图片=音频=视频, 都是
像素整数序列**, 无需任何模态编码器, 用一套整数点积原生处理。

关键创新是 **4态不同起点叠加态并行** 作为贯穿性架构原则: 看、读、想、写/画,
以及文字/图片/音频/视频的所有生成, 均由4个从不同随机起点初始化的独立进程并行执行,
最后投票坍缩输出。这是"真叠加态并行", 区别于经典ensemble(同起点同数据=伪并行)。

核心洞见(2026-08-23): **识别与生成共用同一份权重 W、同一套 4 态、同一套 4 进程并行骨架**。
Hebbian 训练让 W[k] 收敛到"第 k 类的原型像素向量",故 W[k] 本身就是那个字的原型图像。
识别 = 像素点积求 argmax; 生成 = 取 W[k] 第 k 行、4 态并行取行、投票坍缩、阈值化渲染。
两者数学上互为逆运算,无需新模型、无需反向传播、无需新训练。

实验: 4120彝文字形识别器, 8批×4态=32份独立权重, 单态96-98%, 4态投票99.44%;
并行升级后单查询提速约25倍(5.2s→0.2s)。文字/图片/音频/视频共用同一反向QSCL
"画像素"并行核心, 实现统一输出。

## 1. 问题的重新审视: 文字就是图片

人类写字就是画图——笔画出墨迹像素, 与画图出墨迹像素是同一动作。
主流模型违背这一事实: 给图片配image encoder, 给文字配text tokenizer, 再费力对齐。
本文: **像素就是像素**, 8×8二值整数, 直接点积, 原生视觉, 零翻译。

---

## 2. 架构核心: 4态不同起点叠加态并行(贯穿铁律)

### 2.1 什么是真叠加态并行

```
输入
 ├→ 进程0 [seed=1]   独立前向 → 结果0
 ├→ 进程1 [seed=101] 独立前向 → 结果1     ← 同时运行
 ├→ 进程2 [seed=202] 独立前向 → 结果2
 ├→ 进程3 [seed=303] 独立前向 → 结果3
 └→ 真多数投票 → 坍缩输出
```

三要素(缺一即伪并行): (1) 同时运行 (2) 不同随机起点 (3) 最后才汇聚投票。

### 2.2 与经典ensemble的本质区别

| | 经典ensemble | 本架构叠加态并行 |
|---|---|---|
| 起点 | 相同(同初始化同数据) | 不同随机起点 |
| 学到 | 相同知识 | 不同角度知识 |
| 并行 | 常为串行 for循环 | 真多进程并行 |
| 本质 | 平均 | 叠加坍缩(投票) |

**串行 for 循环写4态 = 假的叠加态 = 错。** 本文所有层强制真并行。

### 2.3 为何是4态

性价比平衡: 第5态起边际收益递减(新增态与已有4态知识高度重叠), 但推理开销线性增长。
4态是"足够覆盖不同角度"与"足够快"的平衡点; 未来N态可扩展。

---

## 3. 架构核心: 一个统一生成器(不分类)

主流模型把生成器**分成四类**: 语言模型/图像模型/视频模型/音频模型。
我们**一个都不分**——这是根本优势, 不是分类而是同构。

```
输入=像素整数序列 ──→ [统一生成核心: 4态并行整数点积] ──→ 输出=像素整数序列
                                ↑                    ↑
                          字前缀/图前缀/帧前缀/频谱前缀    字/图/帧/音(同像素)
```

唯一区别是**前缀和播放方式**: 喂字前缀就写字, 喂图前缀就画图, 前缀频谱就发语音,
逐帧喂就放视频。**生成核心本身不区分模态, 输入输出同构都是像素。**

| | 主流(分类) | 本架构(不分类) |
|---|---|---|
| 生成器数量 | 4个(语言/图像/视频/音频) | 1个(统一生成核心) |
| 输入输出 | 各模态各套编码器 | 全像素同构 |
| 并行 | 各模型各自ensemble | 4态不同起点叠加态并行, 一处并行处处并行 |

**不分类 = 一处升级全覆盖。分类是主流模型的包袱, 不是我们的架构。**

## 4. 训练: 纯QEntL感知机对比式更新(已验证收敛)

- 错分类时: W[目标]+=输入数据, W[预测]-=输入数据(对比式)
- 对比 Hebbian 单增强(只加不减, 卡在60%): 对比式可收敛到98%+
- 全部整数运算, 无浮点, 无Python, 纯QEntL + QVM
- 4态独立种子并行训练 → 各自存盘 → 推理时4态并行投票

- 识别(像素→序号)与生成(序号→像素)共用同一份 W、同一套 4 态、同一套并行骨架

- 看/想/写不分类,输入输出同构都是像素(8×8二值整数)
