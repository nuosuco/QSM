## 摘要

主流多模态模型为文字/图片/音频/视频各配独立编码器, 在向量空间"对齐"——
这是一条间接的翻译路径。本文提出根本不同的架构: **文字=图片=音频=视频, 都是
像素整数序列**, 无需任何模态编码器, 用一套整数点积原生处理。

关键创新是 **4态不同起点叠加态并行** 作为贯穿性架构原则: 看、读、想、写/画,
以及文字/图片/音频/视频的所有生成, 均由4个从不同随机起点初始化的独立进程并行执行,
最后投票坍缩输出。这是"真叠加态并行", 区别于经典ensemble(同起点同数据=伪并行)。

核心洞见(2026-08-23): **识别与生成共用同一份权重 W、同一套 4 态、同一套 4 进程并行骨架**。
Hebbian 训练让 W[k] 收敛到"第 k 类的原型像素向量",故 W[k] 本身就是那个字的原型图像。
识别 = 像素点积求 argmax; 生成 = 取 W[k] 第 k 行、4 态并行取行、投票坍缩、阈值化渲染。
两者数学上互为逆运算,无需新模型、无需反向传播、无需新训练。

实验: 4120彝文字形识别器, 8批×4态=32份独立权重, 单态96-98%, 4态投票99.44%;
并行升级后单查询提速约25倍(5.2s→0.2s)。文字/图片/音频/视频共用同一反向QSCL
"画像素"并行核心, 实现统一输出。

## 1. 问题的重新审视: 文字就是图片

人类写字就是画图——笔画出墨迹像素, 与画图出墨迹像素是同一动作。
主流模型违背这一事实: 给图片配image encoder, 给文字配text tokenizer, 再费力对齐。
本文: **像素就是像素**, 8×8二值整数, 直接点积, 原生视觉, 零翻译。

## 2. 架构核心: 4态不同起点叠加态并行(贯穿铁律)

### 2.1 什么是真叠加态并行

```
输入
 ├→ 进程0 [seed=1]   独立前向 → 结果0
 ├→ 进程1 [seed=101] 独立前向 → 结果1     ← 同时运行
 ├→ 进程2 [seed=202] 独立前向 → 结果2
 ├→ 进程3 [seed=303] 独立前向 → 结果3
 └→ 真多数投票 → 坍缩输出
```

三要素(缺一即伪并行): (1) 同时运行 (2) 不同随机起点 (3) 最后才汇聚投票。

### 2.2 与经典ensemble的本质区别

| | 经典ensemble | 本架构叠加态并行 |
|---|---|---|
| 起点 | 相同(同初始化同数据) | 不同随机起点 |
| 学到 | 相同知识 | 不同角度知识 |
| 并行 | 常为串行 for循环 | 真多进程并行 |
| 本质 | 平均 | 叠加坍缩(投票) |

**串行 for 循环写4态 = 假的叠加态 = 错。** 本文所有层强制真并行。

### 2.3 为何是4态

性价比平衡: 第5态起边际收益递减(新增态与已有4态知识高度重叠), 但推理开销线性增长。
4态是"足够覆盖不同角度"与"足够快"的平衡点; 未来N态可扩展。

## 3. 架构核心: 一个统一生成器(不分类)

主流模型把生成器**分成四类**: 语言模型/图像模型/视频模型/音频模型。
我们**一个都不分**——这是根本优势, 不是分类而是同构。

```
输入=像素整数序列 ──→ [统一生成核心: 4态并行整数点积] ──→ 输出=像素整数序列
                                ↑                    ↑
                          字前缀/图前缀/帧前缀/频谱前缀    字/图/帧/音(同像素)
```

唯一区别是**前缀和播放方式**: 喂字前缀就写字, 喂图前缀就画图, 前缀频谱就发语音,
逐帧喂就放视频。**生成核心本身不区分模态, 输入输出同构都是像素。**

| | 主流(分类) | 本架构(不分类) |
|---|---|---|
| 生成器数量 | 4个(语言/图像/视频/音频) | 1个(统一生成核心) |
| 输入输出 | 各模态各套编码器 | 全像素同构 |
| 并行 | 各模型各自ensemble | 4态不同起点叠加态并行, 一处并行处处并行 |

**不分类 = 一处升级全覆盖。分类是主流模型的包袱, 不是我们的架构。**

## 6. 生成对称性:数学推导与实现路径(新心脏)

### 6.1 识别算子(正向,已实锤)

设输入字形像素向量为 $x\in\{0,1\}^{64}$,权重矩阵 $W\in\mathbb{Z}^{515\times 64}$。
识别对每个类别 $c\in\{0,\dots,514\}$ 计算点积:
$$\text{dot}[c]=x\cdot W_{c}=\sum_{j=0}^{63} x_j W_{c,j}$$
预测类号 $k=\text{argmax}_c\ \text{dot}[c]$; 4 态各独立求 $k_i$, 投票坍缩得最终类号。

### 6.2 Hebbian 收敛性质 → W[k] 即原型像素

识别用对比式 Hebbian 更新: 错分样本 $x$ 真类 $t$、误判 $p$ 时
$W_t \mathrel{+}=x$, $W_p \mathrel{-}=x$。 收敛后每个 $W_c$ 是"被加进 $x$ 的次数(支持 $c$)
减去被减走的次数(误归为 $c$)"的累积,故 **$W_c$ 收敛到第 $c$ 类的原型像素向量**
(即所有真类为 $c$ 的像素样本在特征空间的均值方向,整数化)。 换言之 $W_c$ 本身已是
一张可解读的 8×8 原型图像。

### 6.3 生成算子(反向,识别的逆运算)

给定类号 $k$:
1. **取原型** $p^{(i)} = W^{(i)}_{k}$ —— 第 $i$ 态权重矩阵的第 $k$ 行(64 维整数), $i\in\{0,1,2,3\}$
2. **4 态并行坍缩** 逐元素多数投票 $p_j=\text{majority}\{p^{(0)}_j,p^{(1)}_j,p^{(2)}_j,p^{(3)}_j\}$, 得稳定原型像素
3. **阈值化** $\hat x_j = [p_j > \tau]$ (阈值 $\tau$ 取原型中位数或 $p_j$ 最大值的 1/2)
4. **光栅化** 把 $\hat x\in\{0,1\}^{64}$ 排成 8×8 位图, 经字体/描边渲染为可见字形

**逆运算关系**: 识别 $x\to k$ (用整行 $W$ 与 $x$ 点积求最像的行), 生成 $k\to\hat x$ (直接取第 $k$ 行)。
两者操作对象都是 $W$ 的"行",识别按列扫描求最匹配行,生成按行定位读出像素 ——
**数学上恰为互逆操作**。

### 6.4 与反向传播/新训练的本质区别
- 不需要新模型: 直接用已有的 $W$, 不引入 $W_{\text{rev}}$
- 不需要反向传播: QVM 无浮点、无梯度算子, 而生成根本不依赖梯度
- 不需要新训练: 原型已随识别训练收敛, 取行即得
- 仍是 4 态真并行: 4 个进程各自取行, 与识别共用同一并行骨架

### 6.5 统一生成的自指闭环
```
识别: 像素x ──(点积+argmax)──→ 类号k
生成: 类号k ──(取W[k]行+投票+阈值+光栅化)──→ 像素x' ≈ x
```
$x\to k\to x'$ 构成近似恒等闭环, 闭环残差 $\|x-x'\|$ 是生成的可量化质量指标。
语言算子3输出序号流, 经算子2收尾逐字渲染, 即得可读文字; 图片/音频/视频同理:
把像素序列按"字/图帧/频谱帧"语义解释播放, 生成核心本身不区分模态。

### 6.6 统一生成的"简单性"根因
(1) 输入输出同构(都是像素), 避免了主流"像素→token→语义→token→像素"的多层翻译;
(2) 看/想/写共用一份 $W$ 与一套并行骨架, "一处升级全覆盖";
(3) 生成是识别逆运算, 无需任何额外学习信号。
这正是"生成=识别对称反向"的核心价值 —— 它把"多模态统一生成"从
"训练四套大模型"降维成"取行+投票+光栅化"三步整数运算。
