## 二、投资与交易的区别

投资与交易，看似都在金融市场里操作，但二者的底层逻辑截然不同。

**投资的本质是讲信仰——只考验投资人一件事：看方向的能力。**

巴菲特买公司，本质上问的是"我信不信你这个团队"。他押注的是对人和方向的判断，是对长期价值的信仰。投资人做决策的核心依据是"信不信"，而非短期的价格波动。

**交易者没有信仰，任何行为到了交易者眼里都是为了高抛低吸。**

交易者看待市场的方式完全不同。在交易者眼中，没有什么是不可卖的，没有什么是不可买的。一切标的、一切消息、一切趋势，最终都只是高抛低吸的素材。交易者不关心"这个公司好不好"，只关心"这个价格能不能赚差价"。

**真正的投资人和职业交易员都不依赖市场行情。**

这是二者共同的高级特征。真正的投资人靠的是对方向的判断，行情好坏只是时间问题；职业交易员靠的是交易系统，无论行情涨跌，系统都在运行。只有散户才依赖行情——行情好就赚钱，行情差就亏钱，完全被动。

**自我审核：我是个什么人，我就去做什么事。**

这是最朴素也最重要的原则。如果你是信仰型的人，就去做投资；如果你是规则型的人，就去做交易。不要用投资的心态做交易，也不要用交易的方式做投资。认清自己，才能找到正确的路径。

## 三、交易系统的核心概念——Rule

### 什么是Rule？

Rule就是过滤器、法则——什么品种在什么市场条件下开仓/不开仓。

Rule的核心在于**一致性**：3年前同等情况下不开仓，1年前同等情况下也不开仓，今天同等情况下同样不开仓。反过来也一样，该开仓的条件出现时，无论当时心情如何、市场氛围如何，都必须开仓。这才叫Rule。

### 没有Rule的人就是散户/韭菜

散户的典型特征：**完全相同情况下，有时做单有时不做，有时追单有时不追，有时止损有时飘仓。**

同样的技术形态、同样的市场信号，今天心情好就做，明天心情差就不做；今天胆子大就追，明天害怕了就缩手；今天严格止损，明天又觉得"再等等看"。这种行为的本质就是没有Rule——没有规则，没有一致性，完全凭情绪和直觉行事。

### 双标就是没有Rule

**不能因为对象不同就改变标准。** 很多人对自己喜欢的品种就放宽标准，对不喜欢的就收紧标准；对大资金就谨慎，对小资金就随意。这种双标行为本质上就是没有Rule。Rule一旦建立，就必须对所有对象、所有情况一视同仁地执行。

### 建立Rule的两步法

**第一步：改变思想，结束双标，建立Rule的概念。**

这是最根本的转变。从"我想怎么做"变成"Rule要求我怎么做"。从"我觉得这个好"变成"Rule说这个符合条件"。思想的转变是第一步，没有这一步，后面的一切都是空谈。

**第二步：测试Rule，拿结果说话，拿数据说话。**

Rule建立之后，不是靠感觉判断它好不好，而是用数据验证。回测多少次？胜率多少？最大回撤多少？盈利分布如何？这些都需要用数据说话，而不是靠主观感受。

### 不要以个人好恶为Rule

**你不喜欢的点未必是缺点，让你不喜欢的男人可能是马云。**

这句看似玩笑的话，揭示了深刻的道理：个人好恶不等于客观标准。一个交易系统、一个策略、一个品种，你不喜欢它，不代表它不好。Rule的建立必须基于客观的数据和逻辑，而非主观的偏好和厌恶。

## 四、碧树西风的交易系统——捡乌龙指（等错来）

### 大数定律的朴素应用

**基于大数定律：人多的时候一定会有人敲错单。**

这是碧树西风交易系统的起点，也是最朴素、最根本的交易思想。在交易人数足够多的市场中，必然会有操作失误——敲错价格、敲错方向、敲错数量。这些失误就是"乌龙指"。

**只要我把人家敲错的接过来，正常价平仓，就无风险盈利。**

逻辑极其简单：有人以远低于市场价的价格卖出（或远高于市场价买入），我把这个错误单接过来，然后以正常价格平仓，中间的差价就是利润。因为对方是"敲错"的，所以正常价必然存在，利润必然可以实现。

### 08年的起点

**08年从"等错来"开始，不懂量化，唯一坚持的就是基于大数定律的朴素思想。**

碧树西风最初并不懂什么量化模型、什么算法交易，他只是坚信一个朴素的道理：人多了，一定会犯错。只要等，一定会等到。这个朴素的信念，支撑了整个交易系统的起点。

### 捡乌龙指是最简化的交易系统

捡乌龙指同时满足"向下有限、向上无限"两条标准：

- **向下最大亏损**：就是你自己敲错了数字或方向带来的损失。除此之外只要不敲错，没有亏损可能——要么赚，要么赚不到。
- **向上无限**：乌龙指的幅度不可预测，可能很小，也可能很大，理论上没有上限。

这是最简化的交易系统，因为它完美地体现了交易系统的核心逻辑：**亏损可控，盈利可期。**

### 等错来与等风来的数学本质

**等错来=等风来的数学本质一样，都是大数定律。**

"等风来"是等待市场出现大幅波动，"等错来"是等待市场出现操作失误。二者的数学本质相同：只要样本量足够大，事件必然发生。区别只在于等待的对象不同——一个是市场波动，一个是人为失误。

### 巴菲特的捡烟蒂

**巴菲特早期的捡烟蒂本质上就是捡乌龙指——从数学上证明了一定能赚到钱。**

巴菲特早期投资的"捡烟蒂"策略，就是在市场上寻找被严重低估的公司。这些公司之所以被低估，往往是因为市场情绪的过度反应（本质上是市场犯的"错"）。从数学上看，捡烟蒂和捡乌龙指的盈利逻辑完全一致：利用他人的错误获利，且亏损有限。

### 交易系统的演进

**后续发展：等风来→等错来→等温降→倒吹风。**

从最初等待市场波动，到捕捉操作失误，到利用温度（波动率）下降，再到逆向操作——交易系统的演进始终围绕"大数定律"和"向下有限、向上无限"的核心逻辑展开，不断升级和细化。

## 五、交易系统的衡量标准

### 两个核心指标

#### 1. 向下有限，向上无限

这是交易系统的第一衡量标准。一个好的交易系统，必须保证亏损是有上限的，而盈利是（至少理论上）没有上限的。

具体说明：假设每10%为一个标尺，交易系统执行一万次后，盈利分布可能如下：

- 亏10%有4000次
- 不赚不亏2000次
- 赚10%有3000次
- 赚20%有800次
- 赚50%有150次
- 赚100%有40次
- 赚500%以上有20次

**重点：亏超过10%的，0次！**

这意味着，无论执行多少次，单次亏损永远不会超过10%。分界线左侧的亏损总和，要被右侧的盈利包裹住。而**超过500%的20次才是真正的利润来源——这就是肥尾效应。**

**9980次交易的作用是打平，保持资金池回归正数，等待最后20次暴利。**

绝大多数交易不是用来赚钱的，而是用来维持系统运转、保持资金不大幅缩水的。真正的大利润来自极少数的"肥尾"交易。这就像开赌场——绝大多数时间赌场只是维持运转，真正的大利润来自那些偶尔下大注还输了的赌客。

#### 2. 最大连续亏损次数

**10000次中连续10%亏损不超过5次，最大回撤40%。**

最大连续亏损决定了你能否活着等到肥尾。如果连续亏损10次，最大回撤就是65%以上，这对心理和资金都是毁灭性的打击。控制最大连续亏损，就是控制生存概率。

### 资金管理

**本金5万→500万→取出250万→250万→5000万→取出2500万**

**取出的钱永远不会再投入市场，确保在任何情况下都有安全垫。**

这是碧树西风的资金管理原则：每次资金大幅增长后，取出一半作为安全垫。这确保了即使在最极端的情况下（比如交易系统失效、市场黑天鹅），你也不会一无所有。安全垫不是用来赚钱的，而是用来保命的。

## 六、构建交易系统的三步法

### 第一步：先让自己变成刘备——提升认知

刘备的核心能力不是打仗，而是识人、用人、定方向。在交易领域，提升认知就是理解市场、理解自己、理解交易的本质。没有这个认知基础，后面的步骤都是空中楼阁。

### 第二步：寻找诸葛亮——寻找适合自己的交易系统

有了认知之后，才能找到适合自己的交易系统。不是最好的系统，而是最适合的系统。每个人的性格、资金、时间、能力都不同，交易系统也必须因人而异。

### 第三步：才是赚钱——基于交易系统进行交易

只有在前两步完成之后，才轮到赚钱。而大多数人的问题恰恰在于：**上来就想赚钱，加大投入，结果一塌糊涂。**

### 碧树西风自己的经验

**头两年没挣到钱，第一年小亏，第二年赚了150块RMB。**

但这两年的价值远超金钱：

- 这期间赚到了**八成以上的认知**
- 成本只是两年时间+几万块启动资金

**耐心是优于绝大多数人的地方。** 大多数人亏钱，不是因为不够聪明，而是因为不够耐心。他们急于求成，在没有认知基础和交易系统的情况下就大举投入，结果必然是亏损。

## 七、投资三原则（来自付费文章《我建议你不要看完》）

### 原则一：永远的"低买高卖"

**第一层：每次都不怎么亏钱，次数多了自然就赚钱了。**

低买高卖不是一句废话，而是最核心的盈利逻辑。买得低，意味着亏损的空间小；卖得高，意味着盈利的空间大。只要每次亏损都有限，次数多了，盈利自然累积。

**第二层：买得低，安全周期就长，留给操作的时间就越充裕。**

买得低不仅仅是为了少亏，更重要的是争取时间。买得越低，价格回到成本线的时间越长，你就有越多的时间来应对市场变化。时间就是安全边际，时间就是操作空间。

### 原则二：翻台率与风险的平衡

**通过大量尝试与数据，构建胜率与赔率的平衡点。**

翻台率是餐饮业的术语，指桌子的使用频率。在交易中，翻台率就是交易频率。高频交易翻台率高，但单次利润小；低频交易翻台率低，但单次利润大。关键在于找到胜率与赔率的平衡点——不是追求最高的胜率，也不是追求最大的赔率，而是追求二者乘积的最大化。

**需要下苦功夫，积累大量数据和交易样本。**

这个平衡点不是拍脑袋想出来的，而是通过大量的数据积累和回测验证找到的。没有捷径，只有苦功夫。

### 原则三：一定要待在对冲的环境里

**套利思维——天然控制损失，保障亏损上限。**

对冲的本质是：无论市场怎么走，你都有一个保底。你做多A的同时做空B，只要A和B的相关性足够高，你的亏损就被天然限制了。对冲不是为了追求最大利润，而是为了确保你不会在单边行情中暴毙。

**对冲是为了争取时间，让时间成为朋友而非敌人。**

没有对冲的交易，时间是敌人——持仓越久，风险越大。有了对冲的交易，时间是朋友——持仓越久，均值回归的概率越大，盈利的可能性越高。对冲让你有底气等待，等待本身就是一种策略。

## 八、交易系统的市场适用性

### 交易系统如球拍

**乒乓球需要乒乓球拍，羽毛球需要羽毛球拍。**

交易系统不是万能的，每个交易系统都有其适用的市场和品种。用打乒乓球的拍子去打羽毛球，必然打不好。同样，用趋势跟踪系统去做震荡市，也必然亏钱。

### 交易系统是相生相克的原理——一物降一物

**越是具像化，越容易达成目标——研发的产品就是为了克某个平台某个品种。**

好的交易系统不是泛泛而谈的，而是针对特定市场、特定品种、特定条件设计的。越是具体，越有针对性，越能发挥优势。一个在A品种上表现优异的系统，在B品种上可能完全失效。

### 职业交易者的专精

**职业交易者往往专精一行——汇聚在某一个平台的某一个品种上把自己做成最大的克星。**

**聚焦起家→有了根据地→再招兵买马。**

职业交易者的路径是：先在一个品种上做到极致，建立稳定的盈利来源（根据地），然后再逐步扩展到其他品种。而不是一开始就什么都做，什么都做不好。

### 散户的问题

**今天看这个好明天看那个好，没有根据地，到哪都是麻瓜。**

**每个山头都有职业玩家守着打埋伏。**

散户最大的问题就是没有根据地。今天做股票，明天做期货，后天做外汇，每个领域都是浅尝辄止，而每个领域都有深耕多年的职业玩家等着收割。散户到了任何一个领域，都是职业玩家的猎物。

## 九、为什么迟迟无法稳定盈利

### 坑1：不是连续交易的——要跑系统就要跑完整

交易系统是一个完整的闭环，不能只跑一半。今天跑系统，明天不跑，后天又跑——这种断断续续的执行方式，等于没有系统。系统的有效性建立在连续执行的基础上，断断续续的执行只会导致系统的统计优势无法体现。

### 坑2：交易系统的市场适用性问题——没有根据地

如前所述，没有根据地就意味着在别人的地盘上作战，胜率天然偏低。必须找到适合自己的品种和市场，建立根据地，才能稳定盈利。

### 只有两次可以赌运气

**人这辈子只有两次时机可以赌运气：出道时（天然带了止损）和临终时（天然不需要止损）。**

- **出道时**：你一无所有，输了也不过是回到原点，天然带了止损——最多亏光。
- **临终时**：你已经不需要为未来负责，输了也不影响任何人，天然不需要止损。

**其余时候都必须按系统执行。** 在这两个极端之间的人生阶段，你都有责任、有牵挂、有未来，不能赌运气。赌运气等于把命运交给随机，而系统是把命运交给概率。概率和随机的区别在于：概率是可计算的，随机是不可计算的。

## 十、高频量化交易的核心

### 碧树西风的交易领域

**碧树西风做的是国际金融市场高频量化交易。**

高频量化交易的特点是：持仓时间极短（毫秒级到秒级），交易频率极高（每天数千到数万笔），单笔利润极小（可能只有几个基点），但累积起来利润可观。

### 做高频量化跟偷钱也没多大区别

**不赌涨跌，盈利不是最困难的。**

高频量化交易不赌市场的方向，而是捕捉市场中的微小价差和机会。这种交易方式不依赖市场涨跌，而是依赖市场的微观结构和交易机制。盈利不是最困难的部分——因为只要系统运行，利润自然累积。

**最困难的是完善交易系统，提炼出交易思想。**

### 前两年的困境

**前两年不赚钱因为手续费太高，盈利被手续费抵消。**

在交易系统的早期，单笔盈利可能还不足以覆盖手续费，导致整体不赚钱。但碧树西风的核心判断是：

**手续费必然下降（交易平台竞争），一旦下降盈利快速增加。**

这是一个基于逻辑的判断：交易平台之间的竞争必然导致手续费下降，而手续费下降后，原本被手续费吞噬的盈利就会释放出来。这个判断后来被验证了——随着交易平台的竞争加剧，手续费确实大幅下降，盈利快速增加。

### 选择高频量化的原因

**充满流动性，银子始终手里，不像TO B生意被卡着脖子。**

高频量化交易的最大优势是流动性——资金随时可以进出，不存在被套牢、被锁定的风险。这与很多TO B生意形成鲜明对比：TO B生意中，你的客户可能拖欠货款、可能违约、可能让你陷入被动，而在高频量化交易中，银子始终在自己手里。

### ALL IN等于放弃选择权

**即使99%胜率也不应该ALL IN。**

ALL IN的本质是放弃选择权。一旦ALL IN，你就失去了调整、止损、转向的能力。即使有99%的胜率，那1%的失败概率也可能导致毁灭性的后果。永远保留选择权，永远有余地，这是交易的核心原则之一。

### 持仓时间与执行纪律

**持仓时间越短，人越来不及干预，越能严格执行算法。**

这是高频量化交易的一个隐性优势：持仓时间短到人来不及干预，算法就能严格执行。而在低频交易中，持仓时间长，人有足够的时间去犹豫、恐惧、贪婪，从而偏离交易系统。持仓时间越短，人为干扰越少，系统执行越纯粹。

## 十一、人性与交易

### 散户最大的弱点

**太想一把赢回来——像失去孩子的父母。**

这是散户最致命的心理弱点。亏损之后，不是冷静分析、按系统执行，而是急于翻本，加大投入，结果越亏越多。这种心理就像失去孩子的父母——悲痛之下做出极端的、不理性的行为，最终往往导致更大的悲剧。

### 职业选手的围猎策略

**像狼群：先给牛开个口子让它受伤→受伤后惊慌失措→围师必阙。**

职业选手的策略是分步骤的：

1. 先制造一个伤口——让散户产生亏损
2. 等待恐慌——散户在亏损中惊慌失措
3. 围师必阙——故意留一个出口，让散户朝错误的方向"逃跑"

**策略本质：利用你自己的力量来完成对你的绞杀。**

职业选手不需要用多大的力量来对付散户，只需要引导散户自己犯错。散户的恐惧和贪婪，就是职业选手最好的武器。

### 溺水的比喻

**溺水的人大都不是淹死的，是挣扎过程中自己把自己弄死的。**

溺水者因为恐慌而胡乱挣扎，消耗体力，最终力竭而亡。如果保持冷静，漂浮在水面上，反而可能等到救援。交易中的散户也是一样——亏损后恐慌操作，越操作越亏，最终把自己"挣扎"死了。

### 稳定盈利需要什么

**投资稳定盈利需要的不是聪明，是足够傻足够死板。**

聪明的交易者往往过度思考、过度操作，总想找到更好的入场点、更优的出场点。而真正稳定盈利的交易者，是像机器一样执行系统的人——该买就买，该卖就卖，该止损就止损，没有任何犹豫和变通。

### 巴菲特也控制不住自己

**捡烟蒂亏损多次，因为人性干扰算法。**

即使是巴菲特，在执行"捡烟蒂"策略时也多次亏损。不是策略有问题，而是人性干扰了算法——恐惧、贪婪、犹豫，这些人性弱点即使对巴菲特也无法完全避免。

**手动捡乌龙指不是算法有问题，而是人有问题。**

碧树西风在手动捡乌龙指时也遇到了同样的问题：算法是对的，但人在执行过程中会偏离算法。这就是为什么量化交易比手动交易更可靠——不是因为算法更聪明，而是因为算法没有情绪。

### 格雷厄姆的算法要求

**尽量缩短持仓时间。**

格雷厄姆（巴菲特的老师）的算法中，持仓时间越短越好。因为持仓时间越长，人性干扰的可能性越大。缩短持仓时间，就是减少人性干扰的机会，让算法执行得更纯粹。

## 十二、量化思维与情绪思维

### 两种思维模式的对立

**大部分人是情绪思维，容易被情绪左右。**

情绪思维的特征是：涨了就兴奋，跌了就恐惧；赚了觉得自己是天才，亏了觉得市场有问题。情绪思维的人，决策完全被当前的情绪状态驱动，没有一致性，没有规则。

**应该只关注概率，概率才是真实，具体发生的事情反而不重要。**

量化思维的核心是：不关注单次交易的结果，只关注概率分布。单次交易可能赚也可能亏，但只要概率分布有利，长期必然盈利。具体发生了什么不重要——因为单次结果是随机的，概率分布才是真实的。

### 情绪化思维的本质

**情绪化思维就是想一出是一出，没有系统性，没有规则。**

今天看到利好就追，明天看到利空就跑；今天听这个消息，明天听那个建议。这种思维方式的本质就是没有系统——没有规则，没有一致性，完全被外界信息牵着鼻子走。

### 能力圈

**只做自己能力圈内的事情多么困难。**

知道自己的能力圈在哪里，并且只做能力圈内的事情，这听起来简单，做起来极其困难。因为市场上有太多诱惑，太多"看起来不错"的机会，太多"别人都在赚"的行情。克制住跳出能力圈的冲动，比任何交易技巧都难。

### 找到并坚守

**找到一个能够稳定盈利的交易系统，长期做这件事必然会往好的方向发展。**

这是最朴素的道理，也是最容易被忽视的。找到系统不容易，坚守系统更难。但只要系统是经过验证的、有统计优势的，长期执行必然盈利。关键在于：**长期执行**——这四个字，淘汰了绝大多数人。

## 十三、核心思维模型

### 1. 降维观察

**永远站在更高维度看问题，从时空观向下进行降维打击。**

降维观察的核心是：不要陷入问题的细节中，而是跳出来，站在更高的维度审视全局。就像三体人看地球人——你在二维平面上纠缠不清的问题，在三维空间中一目了然。交易中的降维观察，就是从宏观的时空维度理解市场的运行规律，而不是在微观的价格波动中迷失方向。

### 2. 信息不对称论

**财富、权力、阶层的差距本质都是信息不对称。**

所有的不平等，归根结底都是信息的不平等。谁掌握了更多的信息、更早的信息、更准确的信息，谁就占据了优势。交易中的信息不对称尤为明显——职业交易者拥有的信息、数据、工具，远非散户可比。缩小信息差距，是缩小一切差距的前提。

### 3. 终局倒推

**站在人生终点回看财富曲线，从终点倒推今天该做什么。**

终局思维的核心是：不要从现在出发去想未来，而是从未来出发来回推现在。站在人生的终点，回看自己一生的财富曲线，你会希望这条曲线是怎样的？然后倒推回来，今天应该做什么选择、做什么投资、做什么准备。这种思维方式，能让你跳出当下的焦虑和迷茫，做出更清醒的决策。

### 4. 系统>运气

**建立交易系统/思维框架，让结果可复制。**

运气是不可复制的——今天运气好赚了，明天运气差可能亏回去。但系统是可复制的——只要系统有统计优势，长期执行必然盈利。系统>运气的本质是：**不要依赖不可控的因素，要依赖可控的规则。**

### 5. 分清两种风险

- **市场风险**：不可避免要承受。市场波动、黑天鹅事件、政策变化——这些风险是市场本身固有的，你无法完全规避，只能管理。
- **自找的风险**：情绪驱动的追涨杀跌，必须消除。这种风险不是市场给你的，而是你自己给自己制造的。追涨杀跌、频繁操作、不设止损——这些都是自找的风险，完全可以且必须消除。

### 6. 熵减行动律

**不要因为"未来注定"而颓废，努力像呼吸一样自然。**

熵减行动律的核心是：即使你知道长期的结果大概率是好的，也不能因此躺平。努力应该是常态，像呼吸一样自然——不是因为焦虑而努力，不是因为恐惧而努力，而是因为努力本身就是正确的生活方式。在交易中，这意味着即使系统长期盈利，也要持续优化、持续改进、持续执行。

## 十四、市场预测与交易

### 要有预测，但不能只靠预测

**预测只能用来当预案。**

交易中必须有预测，但预测的作用不是指导操作，而是制定预案。预测市场可能涨，就制定涨的预案；预测市场可能跌，就制定跌的预案。但无论预测如何，最终的操作依据是交易系统的信号，而不是预测本身。

### 职业选手与预测

**职业选手不是靠预测，但他有预测——像名将出兵前一定有预案。**

名将出兵前一定有预案，但不会把预案当结果。预案是准备，不是预判。职业交易者也是一样：有预测、有预案，但不会因为预测对了就沾沾自喜，也不会因为预测错了就否定自己。预测的价值在于让你有准备，而不是让你有把握。

### 高手指望什么

**指望变数——关注市场有没有出现确定性的事件。**

高手不赌方向，但赌确定性。当市场出现确定性的事件时（比如某个关键支撑位被突破、某个重大消息落地），高手会果断出手。确定性的大小决定了出手的力度——确定性越高，出手越重。

### 大师在等什么

**在等对手露出破绽，你不动他不动，你露出破绽他就咬死。**

大师的耐心是惊人的。他们可以长时间不动，等待对手犯错。一旦对手露出破绽，他们会像猎豹一样精准出击，一击致命。这种交易方式的核心是：**不创造机会，只捕捉机会。**

### 散户与高手的区别

- **散户问题**：什么在他眼里都是机会，什么都去做。没有筛选、没有过滤、没有标准，结果什么都是半吊子，什么都做不好。
- **高手**：三千弱水只取一瓢饮——取符合交易系统条件的那一瓢。高手不是没有机会，而是懂得放弃。放弃99%的"机会"，只做那1%符合系统条件的机会，这才是真正的交易智慧。

人的肉体有局限——会恐惧、会贪婪、会疲惫、会犯错。但系统没有这些局限。把你的思想、理念、经验提炼成系统，让系统代替你执行——这就是让A（思想/理念）超越肉体限制。系统不会恐惧，不会贪婪，不会疲惫，不会犯错——它只会忠实地执行你赋予它的规则。

这就是交易系统的终极意义：**让你超越你自己。**

## 十六、具体操作方式详解（2026-08-14 新增）

### 16.1 捡乌龙指的正确操作

**必要条件：必须有参考系/坐标系**

同一品种至少有两个交易点（不同平台或不同厅）可交易。

#### 正确操作（文章999、1009明确）

```
场景：平台A的厅1出现跌停（有人敲错价格）

操作步骤：
1. 在厅1以跌停价买入
2. 同一时间，在平台B/厅2做空等额头寸
3. 锁定利润 = 价差 - 手续费×2
4. 瞬间完成，不持仓

原文："接住A平台A1厅100公斤装的银子的跌停，有多少吃多少，是没风险的。
因为同一时间，你就可以在A2厅，或者B平台，同样的额度做空了。"
```

#### ❌ 错误操作（文章999明确否定）

```
直接在厅1抄底，等待几分钟价格恢复后平仓

问题：
- 风险：连续跌停会爆仓
- 人性弱点：亏损50%能扛（损失厌恶），盈利25%就跑
- 文章原文："你在刀头舔血。一次，两次，三次...市场就露出獠牙了"
- 结局："你要的是市场的血，市场要的，是你的命"
```

#### 为什么不能等价格恢复？

**人类损失厌恶不对称：**
- 亏损50%能死扛 → 不会止损
- 盈利25%就跑 → 拿不住利润
- 结果：盈亏比严重不对称，长期必亏

**正确做法：提前锁定回收通道**

```
捡乌龙指的核心 = 捡之前先联系好废品回收站
→ 确认那边2块钱随时收，这边才会1块钱收
→ 废品在我手里，不停留的
```

### 16.2 挂双单做市商策略（早期手动操作）

#### 价格计算公式

```python
# 买单：挂在买一价下方0.1%
buy_price = order_book['bid'] * 0.999

# 卖单：挂在卖一价上方0.1%
sell_price = order_book['ask'] * 1.001

# 理论价差
spread = sell_price - buy_price

# 净利润（必须 > 0）
profit = spread - (fee_rate * buy_price + fee_rate * sell_price)
```

#### 执行规则（定死，不可更改）

| Rule | 内容 |
|------|------|
| Rule 1 | 只挂净利 > 0.1% 的品种 |
| Rule 2 | 单笔最大仓位 ≤ 总资金 20% |
| Rule 3 | 单笔止损 ≤ 总资金 2% |
| Rule 4 | 连续亏损 5 次停止交易 |
| Rule 5 | 盈利取出 50% 永不回市场 |

#### 适用条件

- ✅ 横盘震荡市场
- ✅ 波动率适中
- ✅ 必须看到完整订单簿（买1、买2、买3、卖1、卖2、卖3）
- ❌ 做市商模式不行（只有一个价格看不到深度）

#### 对冲机制

```
同时持有买单和卖单 → 天然对冲

情况A：价格单边上涨
  → 卖单成交，买单浮亏
  → 但整体亏损有限（因为有卖单锁住利润）

情况B：价格单边下跌
  → 买单成交，卖单浮亏
  → 但整体亏损有限

情况C：价格震荡
  → 两单都成交，赚取价差
  → 这是最理想的状态
```

#### 必要条件


## 十七、捡乌龙指与做市策略的本质区别（2026-08-14 补充）

### 17.1 捡乌龙指

**必要条件：**
- 同一品种至少有两个"厅"（交易场所）可交易
- A厅价格异常（如跌停），B厅价格正常

**操作方式：**
```
在A厅以异常价格买入 + 同时在B厅以正常价格卖出
→ 瞬间锁定利润，不持仓等待价格恢复
→ 天然对冲，无风险
```

**关键原则：**
- 必须有参考系！只有一个交易点就不是乌龙指
- 不等价格恢复，不等回归
- 事先锁定回收通道（B厅价格不变）

### 17.2 挂双单做市商策略

**必要条件：**
- 单一平台有完整订单簿（买1、买2、卖1、卖2）
- 不是做市商模式（看不到深度）

**操作方式：**
```
买单价格 = 买一价 × 0.999（下方0.1%）
卖单价格 = 卖一价 × 1.001（上方0.1%）
净利润 = 理论价差 - 手续费×2
```

**本质：**
- 单边挂单，赚买卖价差
- 需要市场震荡
- 有风险，需要对冲机制

### 17.3 核心区别

| 维度 | 捡乌龙指 | 做市策略 |
|------|----------|----------|
| 必要条件 | 至少两个交易点 | 完整订单簿 |
| 操作方向 | 对冲（买A卖B） | 单边（挂双单） |
| 风险程度 | 天然无风险 | 有波动风险 |
| 利润来源 | 异常定价 | 买卖价差 |
| 持仓时间 | 瞬间完成 | 可能较长 |
| 等待条件 | 不需要 | 需要震荡 |

> **碧树西风原文强调：** 捡到钱的关键是"蹲守"+ "锁定回收通道"
> 不等价格恢复，不停留，废品立即出手
