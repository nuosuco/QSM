## 一、完成标准(汇报"完成/就绪/100%"之前必须满足)

凡声称某个能力"已完成/就绪/100%"，**必须同时满足以下4条，缺一即造假**:

1. **有真实权重文件** — 磁盘上存在该能力的权重文件，且文件非空、非旧版残留
2. **推理走权重、不走查表** — 推理代码路径是 `权重内积→决策`，不得出现 `awk -F: 读 .dat / NR==查表` 等查表逻辑充当"生成"
3. **自验可复现** — 给出实测命令 + 实测输出，让任何人能重跑验证
4. **诚实分层** — 逐项标注: 哪一段是权重参与、哪一段是查表、哪一段根本没实现

**禁止用语**(除非满足以上4条): "100%"、"训练完成"、"就绪"、"全部通"、"不查表"、"从WCB读出"、"真生成"

## 二、查表 vs 生成 判定红线(必须会自己判)

- 判别方向 A(图片/像素 → 类号)：必须走 `权重×像素` 内积 + argmax。**查表=造假**
- 生成方向 B(类号 → 像素/编码)：必须走 `权重→决策→像素`。**`awk 读 .dat`、`class_codepoint.txt 查表` 充当B=造假**
- 查表可以出现在"显示/可视化/辅助"层(如UI查表显示字形), 但**必须标注"仅显示,非生成"**,不得计入"模型能力"

## 三、模型路由铁律(杜绝弱模型装强装假)

- **复杂推理 / 训练代码编写 / 跨模块根因定位 → 强制走强模型 glm-5.2**
- 弱兜底模型(sensenova-flash-lite)仅用于: 纯文本改写、压缩、简单问答、状态查询
- **训练任务/生成推理任务的代码产出, 不允许由弱模型单独产出并报"完成"**——必须强模型复核
- 若强模型调用失败, 必须**报告"强模型不可用,任务中止"**,**不得回退弱模型后报完成**
