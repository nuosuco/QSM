# 交易系统构建方案

> 基于碧树西风（记忆承载）16年高频量化交易经验提炼

---

## 一、核心交易思想

### 1.1 捡乌龙指（等错来）
- **数学本质**：大数定律
- **核心逻辑**：人多的时候一定会有人敲错单，接过来正常价平仓就无风险盈利
- **特点**：向下有限（最多自己敲错）、向上无限（乌龙指幅度不可预测）

### 1.2 双向标（Rule一致性）
- Rule就是过滤器：什么品种在什么市场条件下开仓/不开仓
- 3年前同等情况不开仓，1年前同样不开仓，今天同样不开仓
- 双标就是没有Rule

### 1.3 肥尾效应
- 9980次交易打平，等待最后20次暴利
- 超过500%的20次才是真正的利润来源
- 绝大多数交易不是用来赚钱，而是维持系统运转

### 1.4 对冲思维
- 天然控制损失，保障亏损上限
- 对冲是为了争取时间，让时间成为朋友而非敌人

## 二、交易系统构建三步法

### 第一步：提升认知（刘备）
- 理解市场、理解自己、理解交易本质
- 这是最根本的转变：从"我想怎么做"变成"Rule要求我怎么做"

### 第二步：寻找系统（诸葛亮）
- 不是最好的系统，而是最适合的系统
- 每个人的性格、资金、时间、能力都不同

### 第三步：执行赚钱
- 只有前两步完成后才轮到赚钱
- 大多数人的问题：上来就想赚钱，加大投入，结果一塌糊涂

## 三、投资管理原则

### 3.1 本金管理
```
5万 → 500万 → 取出250万
250万 → 5000万 → 取出2500万
```
- 取出的钱永远不会再投入市场
- 确保在任何情况下都有安全垫

### 3.2 风险控制
| 指标 | 阈值 |
|------|------|
| 单笔止损 | 2% |
| 日内止损 | 5% |
| 周度止损 | 10% |
| 最大连续亏损次数 | 10次 |
| 最大回撤 | 40% |

### 3.3 仓位控制
- 单品种仓位 ≤ 总资金20%
- 总仓位 ≤ 80%
- 预留20%现金应对波动

## 四、交易系统衡量标准

### 4.1 两个核心指标

#### 指标1：向下有限，向上无限
- 单次亏损永远不会超过10%
- 分界线左侧亏损总和，要被右侧盈利包裹住
- 肥尾效应：少量暴利交易贡献大部分利润

#### 指标2：最大连续亏损次数
- 10000次中连续10%亏损不超过5次
- 最大回撤40%
- 控制连续亏损就是控制生存概率

### 4.2 翻台率与风险平衡
- 高频交易：翻台率高，单次利润小
- 低频交易：翻台率低，单次利润大
- 关键：找到胜率与赔率的平衡点

## 五、挂双单策略（做市商策略）

### 5.1 核心逻辑
碧树西风早期用手挂双单做市：
- **买单**：在买一价下方挂单（等待价格跌下来成交）
- **卖单**：在卖一价上方挂单（等待价格涨上去成交）
- **利润来源**：买卖价差 - 手续费

### 5.2 执行规则（定死，不可更改）
```
Rule 1: 只挂净利 > 0.1% 的品种
Rule 2: 单笔最大仓位 ≤ 总资金 20%
Rule 3: 单笔止损 ≤ 总资金 2%
Rule 4: 连续亏损 5 次停止交易
Rule 5: 盈利取出 50% 永不回市场
```

### 5.3 挂单价格计算
```
买单价格 = 买一价 × 0.999 (下方0.1%)
卖单价格 = 卖一价 × 1.001 (上方0.1%)
理论价差 = 卖单价格 - 买单价格
净利润 = 理论价差 - 手续费×2
```

### 5.4 风险对冲
- 同时持有买单和卖单，天然对冲
- 价格单边上涨 → 卖单成交，持仓亏损
- 价格单边下跌 → 买单成交，卖单浮亏
- 价格震荡 → 两单都成交，赚取价差

### 5.5 适用条件
- 横盘震荡市场 ✅
- 波动率适中 ✅
- 大数定律：人多了必然有错误，价差必然存在 ✅

## 六、挂双单做市商策略（已验证具体操作）

### 6.1 策略原理

基于碧树西风16年高频量化经验，核心是**挂双单做市**：

- 同时在买一价下方挂买单，卖一价上方挂卖单
- 赚取买卖价差，天然对冲
- 适用于横盘震荡市场

### 6.2 执行规则（定死，不可修改）

```python
RULES = {
    "min_profit_pct": 0.001,      # 只挂净利 > 0.1% 的品种
    "max_position_pct": 0.20,     # 单笔最大仓位 ≤ 总资金 20%
    "stop_loss_pct": 0.02,        # 单笔止损 ≤ 总资金 2%
    "max_consecutive_losses": 5,  # 连续亏损 5 次停止交易
    "profit_withdraw_pct": 0.50,  # 盈利取出 50% 永不回市场
}
```

### 6.3 价格计算

```python
# 买单价格：买一价下方 0.1%
buy_price = order_book['bid'] * (1 - 0.001)

# 卖单价格：卖一价上方 0.1%
sell_price = order_book['ask'] * (1 + 0.001)

# 理论价差
spread = sell_price - buy_price

# 净利润（扣除手续费）
fee_rate = 0.0006  # Bitget maker 费率约 0.06%
profit = spread - (buy_price * fee_rate + sell_price * fee_rate)
```

### 6.4 适用条件

| 条件 | 说明 |
|------|------|
| 市场状态 | 横盘震荡 ✅ / 趋势市场 ❌ |
| 订单簿 | 必须看到买1买2买3卖1卖2卖3 |
| 交易量 | 选择流动性好的品种 |
| 手续费 | 确保净利润 > 0 |

### 6.5 风险对冲机制

```
┌─────────────────────────────────────────┐
│           同时持有买单和卖单               │
├─────────────────────────────────────────┤
│ 情况A：价格上涨 → 卖单成交，买单浮亏       │
│         但整体亏损有限                     │
├─────────────────────────────────────────┤
│ 情况B：价格下跌 → 买单成交，卖单浮亏       │
│         但整体亏损有限                     │
├─────────────────────────────────────────┤
│ 情况C：价格震荡 → 两单都成交，赚取价差     │
│         这是最理想的状态 ✅               │
└─────────────────────────────────────────┘
```

## 七、捡乌龙指策略（需多平台参考系）

### 7.1 必要条件

**必须有参考系/坐标系**——同一品种至少有两个交易平台可同时交易。

### 7.2 正确操作方式

```
当平台A出现异常价格（如跌停）时：
1. 在平台A以异常价格买入
2. 同一时间，在平台B以正常价格做空等额头寸
3. 锁定利润 = 价差 - 手续费×2
4. 瞬间完成，不持仓
```

### 7.3 ❌ 错误操作（文章999明确否定）

```
直接在异常价格抄底，等待价格恢复后平仓

问题：
- 连续跌停会爆仓
- 人性弱点：亏损50%能扛，盈利25%就跑
- 长期必亏
```

### 7.4 当前限制

- 目前只有 Bitget API 配置成功
- 缺少第二个参考平台
- 暂无法实现捡乌龙指策略
- 优先实现挂双单做市商策略
