## 一、推广总策略

**核心逻辑：不卖货，卖"你的病该怎么吃"。**

用户不是来逛商城的，是来问"我痛风发作怎么办""血糖高吃什么能降""血压高能不能食疗"的。小麦告诉他答案，答案里顺便带着有机食材链接。这不是营销，是服务。

**关键洞察：有病痛的人才是最强付费动力。**
- 失眠的人可能忍忍就过了
- 但痛风发作的人、血糖飙高的人、血压降不下来的人，他恨不得今天就找到食疗方案
- 这些人才是最在乎健康、最有动力通过药膳食疗调理的用户
- 他们不是"养生爱好者"，是"健康刚需人群"

**目标人群分层：**
| 层级 | 人群 | 痛点 | 转化动力 | 客单价 |
|------|------|------|----------|--------|
| S级 | 三高/痛风/风湿患者 | 正在痛苦中，急需方案 | 极强 | 高（长期复购） |
| A级 | 失眠/疲劳/亚健康 | 不舒服但能忍 | 中 | 中 |
| B级 | 养生爱好者 | 预防保健 | 弱 | 低 |

**推广闭环：**
```
内容引流（YouTube/公众号/小红书）
    ↓
健康测评（3分钟，零门槛）
  ├── 体质测评（九种体质）
  └── 症状自评（三高/痛风/风湿/失眠/疲劳等）
    ↓
测评结果分享图（带小程序码）→ 裂变
    ↓
小麦出方案："你尿酸偏高，推荐薏米赤小豆汤+忌高嘌呤"
    ↓
食材各2款有机商品 → 淘口令 → 淘宝下单
    ↓
每日食疗提醒 + 指标跟踪 → 长期复购
```

## 三、裂变推广

### 3.1 健康测评裂变（核心钩子）

**原理：** 人天生爱测自己（星座、MBTI、体质），测完爱分享。有病痛的人更爱测——他想知道自己到底什么问题。

**三轨测评（按用户懒惰程度排序）：**

**① AI拍照扫描（最懒用户，0门槛，最强裂变）**
- 原理：用户打开手机摄像头，扫描/拍照眼、耳、鼻、喉、头、皮肤、舌头、手等部位
- AI看图模型分析：面色、舌苔、皮肤状态、眼部特征 → 推断体质/症状倾向
- 用户心理："拍个照就能知道我的体质？太神奇了！" → 分享欲爆棚
- 裂变话术："AI看了我的舌头说我是痰湿质，你也试试？"
- 技术：小程序 `wx.chooseMedia` 拍照/相册 → base64 → `/api/chat/vision` → 看图模型分析
- 扫描体验优先（摄像头实时取景），做不到就拍照（已确认可行）
- 配合文字补充："你还有什么不舒服？"（很多症状只有用户自己知道，但用户懒，拍照是第一步）

**② 体质测评（九种体质，10道题）**
- 适合：养生爱好者、亚健康人群
- 结果：气虚质/阳虚质/阴虚质/痰湿质/湿热质/血瘀质/气郁质/特禀质/平和质
- 分享图："我是气虚质，容易累·怕冷·爱感冒"

**③ 症状自评（病痛人群，15道题）**
- 适合：三高/痛风/风湿/失眠/疲劳等有明确症状的人
- 覆盖症状（12大类）：
  - 🔴 高血压（头晕、头痛、耳鸣、面红、血压偏高）
  - 🟠 高血糖（多饮、多尿、多食、体重下降）
  - 🔶 糖尿病（三多一少、视力模糊、伤口愈合慢、手脚发麻）
  - 🟡 高血脂（头晕、胸闷、肢体麻木）
  - 🟣 痛风/高尿酸（关节红肿热痛、夜间发作）
  - 🔵 风湿/类风湿（关节晨僵、游走性疼痛）
  - ⚪ 失眠（入睡难、易醒、多梦）
  - 🟤 慢性疲劳（持续疲倦、注意力下降）
  - 🟢 脾胃虚弱（腹胀、便溏、食欲差）
  - 🔷 前列腺问题（尿频尿急、夜尿多、会阴坠胀）
  - 🩹 皮肤问题（瘙痒、起疹、干燥脱屑、反复发作）
  - 🫀 血液循环问题（手脚冰凉、麻木、青筋凸起、蹲起头晕）
- 结果："你的症状倾向：高尿酸血症（痛风前期）"
- 分享图："我的尿酸可能偏高！小麦建议：薏米赤小豆汤+忌海鲜啤酒"

**分享图示例：**


**裂变钩子对比：**
| 方式 | 用户成本 | 传播力 | 适合人群 |
|------|----------|--------|----------|
| AI拍照扫描 | 极低（拍一下） | ⭐⭐⭐⭐⭐ | 所有人 |
| 体质答题 | 低（3分钟） | ⭐⭐⭐⭐ | 养生爱好者 |
| 症状自评 | 中（5分钟） | ⭐⭐⭐ | 有明确症状的人 |

**裂变路径：**
```
用户扫码/点击进入小程序
    ↓
选择测评类型：体质测评 / 症状自评
    ↓
答题（3分钟）
    ↓
生成分享图 → 分享到朋友圈/群聊
    ↓
朋友看到 → "我是不是也有这个问题？" → 扫码 → 测 → 分享 → 裂变
    ↓
同时：用户直接问小麦 → 小麦出食疗方案 → 推荐有机食材 → 下单
```

**技术实现：**
- AI拍照：`wx.chooseMedia`（拍照/相册）→ base64 → `/api/chat/vision`（看图模型：sensenova-6.7-flash-lite / agnes-2.0-flash）
- 分享图：canvas 绘制 + `wx.canvasToTempFilePath` 保存
- 网页版：html2canvas 或后端 Pillow 生成
- 分享图带小程序码（`wxacode.getUnlimited` API）
- 测评结果存后端，小麦对话时自动读取（不用重新问）
- 拍照扫描结果 + 答题结果合并，小麦综合判断

### 3.2 内容种草引流

**选题方向（按转化力排序）：**
1. 🔴 病痛类（最高转化）："痛风发作，这碗汤喝3天尿酸就降了""血糖高的人，早餐千万别吃这个"
2. 🟠 症状类（高转化）："失眠10年，这个食疗方让我一觉到天亮""湿气重的5个信号，你中了几个"
3. 🟡 体质类（中转化）："九种体质自测""气虚的人为什么总是累"
4. 🟢 节气类（引流）："大暑养生，这3样东西必须吃""三伏天千万别做这件事"

**公众号/小红书/视频号：**
- 病痛类内容为主（60%），体质/节气为辅（40%）
- 文末：「不确定自己什么问题？扫码问小麦，3分钟出方案」+ 小程序码
- 不硬广，用真实案例（脱敏）+ 食疗方案

**YouTube：**
- 视频描述栏放小程序引导 + som.top 链接
- 评论区置顶互动问题："你是什么症状？评论区告诉我"

### 3.3 社群渗透

**重点社群（按转化力排序）：**
1. 🔴 病友群：痛风群、糖尿病群、高血压群、类风湿群 → 这些人最刚需
2. 🟠 养生群：中医养生群、食疗群 → 有认知基础
3. 🟡 生活群：宝妈群、白领亚健康群 → 需要教育

**策略：**
- 病友群：先分享食疗知识，再说"我做了个小程序能根据你的症状出食疗方案"
- 群主合作：帮群成员免费健康测评
- 每周在群里发一次"本周节气养生提醒"
- 痛风/糖尿病群是金矿——这些人每天都在找"吃什么能降尿酸/降血糖"

### 3.4 签到留存

- 每日签到 + 积分
- 节气养生提醒（"今天大暑，推荐绿豆百合汤"）
- 体质跟踪："你上次气虚，最近好点没？"
- 连续签到奖励：7天送体质深度分析
