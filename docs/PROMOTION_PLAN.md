## 一、推广总策略

**核心逻辑：不卖货，卖"你的体质该吃什么"。**

用户不是来逛商城的，是来问"我最近老累、睡不好、湿气重怎么办"的。小麦告诉他答案，答案里顺便带着有机食材链接。这不是营销，是服务。

**推广闭环：**
```
内容引流（YouTube/公众号/小红书）
    ↓
体质测评（3分钟，零门槛）
    ↓
测评结果分享图（带小程序码）→ 裂变
    ↓
小麦出方案："你气虚，推荐黄芪炖鸡"
    ↓
食材各2款有机商品 → 淘口令 → 淘宝下单
    ↓
签到+节气提醒 → 复购
```

### 2.2 内容生产流水线（全自动）

```

├── 2. 写文案（SenseNova GLM）

│   ├── 小红书版：300字种草 + 标签
│   └── 视频脚本：6-8个镜头 + 旁白文案
│
├── 3. 生成配图（Agnes 2.5 图片模型）
│   ├── 公众号封面图（900×383）
│   ├── 小红书配图（3:4竖版，4-6张）
│   └── 视频补充画面（16:9横版）
│
├── 4. 生成视频片段（Agnes 2.5 视频模型）
│   └── 每镜头5-10秒AI视频片段
│
├── 5. 视频合成（ffmpeg）
│   ├── 拼接片段 + 图片
│   ├── TTS 中文旁白配音
│   ├── 中文字幕（硬字幕）
│   ├── 英文字幕（SRT文件）
│   ├── 背景音乐
│   └── 输出：1920×1080 横屏 MP4
│
├── 6. 发布
│   ├── 公众号 → API 自动发布 ✅
│   ├── YouTube → Data API v3 自动上传 ✅
│   ├── 小红书 → 素材推送给中华，手动发
│   └── 视频号 → 素材推送给中华，手动发

└── 7. 记录
    └── 写入发布日志，追踪数据
```

## 三、裂变推广

### 3.1 体质测评裂变（核心钩子）

**原理：** 人天生爱测自己（星座、MBTI、体质），测完爱分享。

**流程：**
```
用户扫码/点击进入小程序
    ↓
"测测你是什么体质"（3分钟，10道题）
    ↓
生成分享图：
┌─────────────────────────┐
│  🌿 我是【气虚质】        │
│                          │
│  容易累 · 怕冷 · 爱感冒   │
│  气短懒言 · 面色偏黄      │
│                          │
│  小麦建议：黄芪炖鸡补气   │
│  忌：生冷寒凉、过度劳累   │
│                          │
│  [小程序码]              │
│  扫码测测你是什么体质 →   │
└─────────────────────────┘
    ↓
分享到朋友圈/群聊
    ↓
朋友好奇 → 扫码 → 测 → 分享 → 裂变
```

**技术实现：**
- 小程序端：canvas 绘制分享图 + `wx.canvasToTempFilePath` 保存
- 网页版：html2canvas 或后端 Pillow 生成
- 分享图带小程序码（`wxacode.getUnlimited` API）

### 3.2 内容种草引流

**公众号/小红书/视频号：**
- 发"九种体质自测""湿气重的5个信号""三伏天千万别吃这个"
- 文末：「想知道你是什么体质？扫码问小麦」+ 小程序码
- 不硬广，养生内容本身就是流量

**YouTube：**
- 视频描述栏放小程序引导 + som.top 链接
- 评论区置顶互动问题

### 3.3 社群渗透

- 中医养生群、宝妈群、亚健康白领群
- 先提供价值（回答养生问题），再说"我做了个小程序能辨证"
- 群主合作：帮群成员免费体质测评
- 每周在群里发一次"本周节气养生提醒"

### 3.4 签到留存

- 每日签到 + 积分
- 节气养生提醒（"今天大暑，推荐绿豆百合汤"）
- 体质跟踪："你上次气虚，最近好点没？"
- 连续签到奖励：7天送体质深度分析
