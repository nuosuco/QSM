# 捡乌龙指操作指南

## 核心定义（根据文章1009、999）

**什么是乌龙指？**
- 同一品种在至少两个交易点
- A厅有人敲错价格（如10000卖成1000）
- B厅价格正常不动（参考系）
- 这就是乌龙指

**判断标准：**
- 有参考系 = 是乌龙指
- 只有一个交易点 = 只是价格波动，不是

## 操作步骤

### 第一步：发现异常价差
- 持续扫描所有币种在多个交易所的价格
- 发现价差突然扩大到异常程度（如>2%）

### 第二步：确认参考系
- 检查其他交易所价格是否正常
- 检查同交易所永续合约是否正常
- 确认只有一个交易所价格异常

### 第三步：同时挂单
- 在低价交易所市价买入
- 在高价交易所市价卖出
- 同一时间完成，不等恢复

### 第四步：结算
- 两边平仓
- 锁定利润

## 为什么不用杠杆？

```
对冲持仓 = 天然控制风险
加杠杆 = 一边成交一边裸奔 = 爆仓
```

## 风控规则

```
单笔止损 ≤ 总资金 2%
单品种仓位 ≤ 总资金 20%
连续亏损 5 次暂停交易
盈利取出 50% 永不回流
最大回撤控制 < 40%
```
