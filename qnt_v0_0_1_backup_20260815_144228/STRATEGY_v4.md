## 一、核心思想（必须背诵）

### 1.1 捡乌龙指 = 等错来

**数学本质：大数定律**
```
人多了 → 一定有人敲错单 → 我等就对了
```

**正确定义：**
- 同一品种在**至少两个交易点**
- A厅价格异常偏离（参考系B厅正常）
- 在A厅买入异常价格 + B厅卖出正常价格
- **瞬间锁定，不等价格恢复**

### 1.2 为什么是零风险

```
永续多单 + 现货空单 = 天然对冲
→ 无论涨跌，都有另一边对冲
→ 利润来自价差，不是方向判断
→ 只要对冲成立，就没有方向风险
```

### 1.3 为什么用高杠杆

```
本金$1，200倍杠杆 → 持仓$200
价差3% → 利润$6
不加杠杆：利润$0.03
加200倍：利润$6
```

### 1.4 关键区别

| 概念 | 捡乌龙指 | 做市策略 | 抄底等恢复 |
|------|----------|----------|-----------|
| 必要条件 | ≥2交易点 | 完整订单簿 | 只有1个交易点 |
| 操作方式 | 同时对冲 | 挂双单 | 单边持仓 |
| 风险程度 | 零风险 | 有波动风险 | 高爆仓风险 |
| 是否等恢复 | 不等 | 不确定 | 等恢复 |
| 利润来源 | 别人错误 | 买卖价差 | 价格回归 |

## 二、Post-Only订单机制

### 2.1 原理

```
Post-Only = 只做Maker，不做Taker

如果订单会立即成交 → 自动取消 ❌
如果订单挂单等待 → 成功 ✅

目的：确保自己是挂单方，不被主动成交（Taker）
```

### 2.2 操作示例

```python
# 挂永续买单（Post-Only）
perp_order = bitget.create_order(
    symbol='RVN/USDT:USDT',
    type='limit',
    side='buy',
    amount=10000,
    price=perp_bid - 0.00001,  # 略低于bid
    params={'postOnly': True}   # 关键参数！
)

# 挂现货卖单（Post-Only）
spot_order = bitget.create_order(
    symbol='RVN/USDT',
    type='limit',
    side='sell',
    amount=10000,
    price=spot_ask + 0.00001,  # 略高于ask
    params={'postOnly': True}   # 关键参数！
)
```

### 2.3 结果分析

```
情况A：两单都成交 ✅
  → 永续多单 + 现货空单
  → 完美对冲，利润锁定

情况B：只有一单成交 ⚠️
  → 另一单自动取消（因为是Post-Only）
  → 不会单边暴露，无爆仓风险

情况C：两单都取消 ❌
  → 市场深度不足或价差太小
  → 不操作，等待下次机会
```

## 三、风控规则（定死）

```
Rule 1: 单笔仓位 ≤ 总资金 20%
Rule 2: 单笔止损 ≤ 总资金 2%
Rule 3: 连续亏损 5 次暂停交易
Rule 4: 最大回撤 40% 停止交易
Rule 5: 盈利取出 50% 永不回流
Rule 6: 净利必须 > 0.1% 才执行
```

## 五、执行流程

### 5.1 扫描阶段

```
1. 获取多个交易所的同一币种价格
2. 计算价差
3. 扣除双边手续费（0.12%）
4. 净利 > 0.1% → 标记为机会
5. 记录到数据库
```

### 5.2 执行阶段

```
1. 检查风控规则（仓位、连续亏损、回撤）
2. 计算合适仓位大小
3. 同时挂出永续买单 + 现货卖单
4. Post-Only确保只做Maker
5. 检查成交状态
6. 两边成交 → 立即平仓锁利
7. 单边成交 → 另一单自动取消
```

### 5.3 结算阶段

```
1. 计算净利润
2. 取出50%（永不清回市场）
3. 记录交易到数据库
4. 更新账户状态
5. 重置连续亏损计数（如果有盈利）
```

## 八、常见问题

### Q1: 为什么不直接用市价单？

**A:** 市价单会立即成交，可能导致单边暴露（永续成交但现货没成交）。Post-Only确保我们只做挂单方，不会被主动成交。

### Q2: 为什么不等价格恢复？

**A:** 人类的损失厌恶不对称：
- 亏损50%能死扛（不会止损）
- 盈利25%就跑（拿不住利润）
- 结果：盈亏比严重不对称，长期必亏

### Q3: 为什么必须对冲？

**A:** 对冲是天然控制损失：
- 永续涨 → 现货亏，但永续赚更多
- 永续跌 → 永续亏，但现货赚更多
- 无论如何，都有另一边对冲

### Q4: 手续费怎么算？

**A:** 
```
永续手续费: 0.06%（Maker）
现货手续费: 0.06%（Maker）
双边总手续费: 0.12%

净利 = 价差 - 0.12%
要求净利 > 0.1% → 价差必须 > 0.22%
```
