# QNT - Quantum Superposition Trading Network

## 核心概念：量子叠加态并行

1. **N态不同起点**：多个独立Agent从不同初始权重训练
2. **各态独立并行**：每个Agent独立运行，互不干扰
3. **各态学到不同权重**：各自学习不同市场模式
4. **观测坍缩**：定期合并所有态的权重（集成学习）
5. **最终模型含所有态知识**：比单个模型更鲁棒
