## 📚 核心架构

```
C种子 (qcl_bootstrap.c)
  ↓ 编译
QCL编译器 (qcl.qentl)
  ↓ 编译
QVM虚拟机 (qvm.qentl)
  ↓ 运行
标准库 (lib/*.qentl)
  ↓ 运行
HTTP服务器 (server_qentl.qentl)
  ↓ 服务
QOS平台 (qsm.som.top)
```
